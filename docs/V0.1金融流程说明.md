# V0.1 金融流程说明

## 1. 这套系统到底在做什么

Factor Miner 要回答一个很朴素的问题：某个今天能够观察到的股票特征，是否与股票之后一段时间的收益存在稳定关系？

例如，“过去二十个交易日涨得更好的股票，接下来五个交易日是否仍然更强”是一条候选假设。系统不会因为它听起来合理就接受它，而是要求先写清楚理由、方向和失败条件，再用统一规则检验。

V0.1 的终点只是“通过可信可见验证的候选因子”。它并不证明因果关系，也不代表已经可以拿钱交易。

## 2. 一条候选因子的完整旅程

### 第一步：先写假设，后看答案

研究者在看到结果前，先登记因子的金融主张、作用机制、预期方向、可观察代理、竞争解释、失效方式和证伪路径。评价区间、股票池、收益标签、显著性门槛和试验总预算也同时冻结。

这相当于考试前先交答案规则，避免看到结果后再改故事或挑选最有利的统计口径。

### 第二步：确认公式只使用当时可知的信息

系统只允许白名单公式，并检查滚动窗口、位移和字段可得时间。V0.1 还会截断未来数据、扰动未来输入，确认今天的因子值不会随着未来数据变化。

如果未来价格、未来成分股或未来财务状态偷偷影响了今天的信号，候选必须直接失败。

### 第三步：在当日可投资股票池中计算原始因子

真实计算只在公司 Linux 服务器上进行，使用当时可得的全 A 股状态和行情。停牌、上市时间不足或状态不合格的股票按冻结规则处理。

这一层只计算原始因子，不做标准化、中性化或用零填补缺失值，避免把研究处理藏进公式。

### 第四步：定义未来收益

公司 V0.1 固定在收盘后形成信号，最早下一交易日开盘成交。五日标签可写成：

```text
open(t+6) / open(t+1) - 1
```

它表示从下一交易日开盘买入，到五个交易日后的开盘结束观察。这样信号时间和可成交时间不会倒置。

### 第五步：每天做一次横截面排名比较

系统在每个交易日，把股票按因子值排序，也把之后收益排序，再计算两组排名的 Spearman 相关系数，这就是当日 RankIC。

- RankIC 为正：因子值越高的股票，之后收益通常也越高。
- RankIC 为负：因子值越高的股票，之后收益通常越低。
- RankIC 接近零：没有稳定的排序关系。

系统关注许多交易日上的平均 RankIC，而不是某一天碰巧成功。

### 第六步：判断结果是否可能只是运气

连续日期的 RankIC 会互相影响，因此使用 HAC 处理时间相关性。由于研究中会尝试多个候选，V0.1 还用全局研究预算和 Bonferroni 校正提高显著性门槛，并要求平均 RankIC 的绝对值达到最小效果量。

失败、重复或中断的候选仍占用试验名额，不能删除后假装从未尝试。

这里暂不使用 CPCV 和 Deflated Sharpe Ratio。CPCV 需要明确的训练过程、测试折和策略收益路径；Deflated Sharpe Ratio 需要策略收益序列、Sharpe Ratio、偏度、峰度、样本长度和试验数量。原始因子目前只有逐日 RankIC 序列，还没有持仓、换手和策略收益，把这两个方法直接套上去会混淆“因子是否有截面预测关系”和“策略是否具有风险调整后收益”。

### 第七步：排除换名字的旧因子

系统先比较公式结构，再比较不同因子的逐日截面输出。如果新候选只是旧因子的同义写法，或输出高度相关，就保留审计记录但不让它通过。

### 第八步：保存完整审计包

公式、输入版本、代码版本、配置哈希、未来依赖探针、质量检查、RankIC、统计推断和冗余结果必须完整落盘后，账本才能写入终态。中断运行也要明确记录，不能静默消失。

## 3. 为什么输入和答案必须分开

行情与状态属于“答题材料”，未来收益属于“答案”。V0.1 把两者拆成不同数据端口：公式编译、结构去重和未来依赖检查通过之前，程序不得打开未来收益。

这不是普通的软件分层，而是研究可信度的核心控制：研究过程不能提前偷看答案。

## 4. 通过 V0.1 之后仍然缺什么

候选即使通过，仍然没有完成以下工作：

- 密封样本外检验；
- 独立机制验证；
- 组合构建与策略回测；
- 交易成本、容量和冲击评估；
- 生产发布与实盘授权。

所以正确表述是“它值得进入下一阶段研究”，而不是“发现了有效 Alpha”或“可以买入”。

后续进入模型和组合研究时，可以在开发区间使用带清洗与禁运期的 CPCV 检查不同市场路径下的稳定性，再对完整策略收益使用 Deflated Sharpe Ratio 控制策略筛选、非正态收益和回测过拟合。两者都不能替代最终密封样本外检验。

## 5. 当前进度

V0.1 的任务 1 已冻结评价政策、交易时点、股票池和全局试验预算；任务 2 已把因子输入、未来收益和参考因子物理分开。任务 3 至任务 7 尚未完成，因此当前不应启动新的正式可见验证。
