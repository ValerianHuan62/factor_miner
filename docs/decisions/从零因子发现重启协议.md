# 从零因子发现重启协议

## 决策

旧 `huan001–huan367` 与 QuantLake 216 因子全部保留为 `legacy_diagnostic`，不删除历史账本，也不作为新候选的提示词、公式种子或参数模板。新研究使用独立候选目录、研究族和产物根，从经济机制开始重新登记。

## 第一批边界

- 第一批冻结 12 个假设名额，每个假设只允许一个主公式；
- 不允许同一公式批量改窗口、改符号、取对数、套 Rank 或组合多个近义变体；
- 只使用信号时点可得的 `open/high/low/close/volume/amount` 与显式状态字段；
- 基本面因子另开 PIT 研究族，不与量价研究族共享多重检验分母；
- 每个候选必须先登记机制、预期方向、代理变量、竞争解释、失效方式、证伪路径和可核验来源；
- 候选冻结后才能与旧 367 和 QuantLake 216 做 AST、公式和输出相关性查重；查重只负责拒绝重复，不得反向修改新公式；
- 发现期为 2021–2023，确认期为 2024–2026-06；方向不得在确认期翻转。

## 标签合同

信号在周末收盘后形成。标签按全市场交易日历固定使用信号日后第 1 个交易日开盘建仓、第 6 个交易日开盘退出。个股在固定建仓日或退出日不可交易时，该样本缺失；不得删除停牌日后按个股记录向后移动。

标签发布必须通过以下检查：

- 建仓与退出日期完全来自同一冻结交易日历；
- 不存在个股级可变持有期；
- 缺少可执行价格时保持缺失；
- 报告标签覆盖率、持有日历跨度分布、收益分位数与极值；
- 数据异常未解释前不得计算 IC、Sharpe 或训练模型。

## 固定筛选顺序

```text
12 个事前假设与主公式
  → 数据与泄漏门槛
  → IC / RankIC / HAC / 确认期稳定性
  → 统计候选池
  → 与旧库查重及候选间相关性聚类
  → 简单 rolling Ridge 增量检验
  → 最终组合经济门槛
```

单因子 Sharpe、换手、利润集中度、成本压力和分组单调性在统计候选阶段作为警告与排序字段，不删除已经通过统计门槛的模型原材料。最终组合必须重新检查成本后收益、换手、回撤、年度集中度和增量稳定性。

## 结论边界

第一批的目的不是一次找到生产 Alpha，而是验证“独立机制 → 单一公式 → 固定标签 → 统计候选 → 组合增量”的完整链路。确认期已经被查看，只能作为历史诊断；协议锁定后的未来数据才构成新的样本外证据。
