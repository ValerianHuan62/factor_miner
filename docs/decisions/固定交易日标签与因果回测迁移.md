# 固定交易日标签与因果回测迁移

## 结论

自 `standard-panel-v2` 和 `dashboard-real-backtest-v2-causal` 起，Factor Miner 的训练/发现评价与回测采用统一的无未来信息合同。此前美股 `release_v3`、30 因子确认结果及 Dashboard v1 回测包含证券局部 shift 标签、跨分区标签事件和未来可成交过滤风险，只保留为历史审计，不得作为有效研究结论或继续投影。

## 标签与分区

- 信号日 T 的五日 O2O 标签固定为统一交易日历上的 T+1 开盘到 T+6 开盘。
- 每行保存 `label_entry_date` 与 `label_exit_date`；固定事件日缺价格即为 null。
- 发现/训练区间必须登记下一分区起点，并保留 `label_exit_date < next_split_start` 的样本。

## 执行顺序

1. T 日只使用因子值与排名资格冻结名单和权重。
2. T+1 开盘才读取买入状态；未成交权重留现金，不替补、不重试。
3. 计划退出日才读取卖出状态；未成交则持仓和资金继续锁定，逐交易日重试。
4. 成本按真实买卖成交额分别计提；订单和逐日持仓进入审计。
5. 数据终点仍有未合法退出持仓时 fail closed。

## 迁移影响

旧模型、旧方向冻结、旧 IC、旧回测和旧 Dashboard JSON 不能与 v2 结果混用。美股 10 假设 30 因子若要恢复展示，必须从 v2 标准发布重新计算发现区间、重新冻结方向、再运行确认与因果回测；不能只重算 Dashboard。
