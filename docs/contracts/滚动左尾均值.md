# 滚动左尾均值数据合同

`rolling_lower_tail_mean(x, window)` 在单证券完整有限观察窗口中，选取最小 `ceil(window/20)` 个值求平均。比例固定5%，不由候选传入或调参；120观察恰为最差6个观察。并列边界只占固定个数，不插值，也不扩大尾部样本。返回值保留x单位与符号，不自动转成正损失。窗口不足、包含非有限值均为空。

股票毛收益使用精确上一市场日收盘价作为分母，停缺日不顺延。毛收益尾均值等于简单收益尾均值加1，排序相同。测量是个股时间序列尾部，不进行横截面排名、标准化或缺失回填。尾部比单个最差观察更能反映持续的严重损失，但仍可能与波动或其他历史因子高度相关，需按冻结流程检验。

独立排序参考验证算子、边界并列、多证券、缺失、单位、未来信息与完整日历端点。反复负跳跃应降低左尾均值；该响应只验证测量，不证明投资者注意力或坏消息反应不足的机制。
