# 多期限组合预测对照

用户已允许日频、周频和月频研究。本入口先单独改变收益预测期限，保持已有周末信号截面、因子排名预处理、训练历史和模型参数，以辨认预测期限对组合贡献的影响。它不代表日频或月频调仓已经验证，不替代新假设的FaVOR联合研究流程。

`factor-miner run-horizon-models <配置>`绑定已冻结共同特征面板、原模型协议、市场日历和独立的1／5／20日标签发布。所有期限、模型、比较和方向在训练前登记；每个期限的模型与比较占有限预算，继承旧试验历史及已消费状态。原公式、特征方向及旧结果不改写。

预测保留全部信号完整证券，包括未来收益标签未知的证券。训练沿用原156周历史、1周隔离、每4周重训和固定Ridge参数；标签退出事件必须严格早于拟合预测日。20日目标不会因为名称变化而沿用五日purge。各期限的目标列保留真实期限名称。模型系数与事前经济方向冲突时单独记录，不能把反向系数解释成原假设通过。

同一期限下，各模型使用完全相同的信号截面、目标与日期，比较原八、加入全部新增、单独加入、逐项移除。只在IC统计时排除缺失标签和跨年度退出事件，预测本身不删除。配对RankIC报告总体、逐年变化以及冻结的HAC和校正p值。这里使用周度IC序列，HAC滞后单位是周；不能照搬每日IC的滞后单位。

当前验证2024与历史复核2025均已被观察。多期限选择属于已消费历史上的探索，不能在本次结果后宣称新的密封样本外或据最优期限直接晋级。每个期限完整保留预测、训练审计、系数冲突、IC和失败记录。通过预测对照后仍需独立的实际调仓、因果现金记账、成本、终值、冗余及机制检验。

合成回归覆盖长标签污染攻击、未知标签预测保留、跨年度事件统计清除和三个期限端到端执行。五日对照另外与原同名模型预测复现核对；不同年度边界统计口径分开说明。
