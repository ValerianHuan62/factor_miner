# 既有候选联合贡献事后诊断

本合同对应 `joint-contribution-diagnostic-v1`。用户授权对既有 A 股候选开展有限的组合诊断；不新增候选，不恢复缺失历史检验族，不改变原 FaVOR、单因子准入或正式确认合同。研究问题是已有输入之间的替代关系，以及它们对指定多头组合的参考净表现贡献。

## 登记与输入

正式入口为 `factor-miner register-joint-diagnostic <配置> <新目录>` 和 `factor-miner run-joint-diagnostic <已登记目录>`。登记先绑定累计候选库、发布回执、原计划、候选 Spec、原始矩阵、数据发布和账本内容身份。原方向来自事前条件，不按结果改号。运行再次核验，拒绝覆盖或并发重复启动；错误保留已写结果及失败记录。

配置由 `JointStudyConfig` 严格校验，要求显式的候选数、发现区间、评价区间、禁止读取起点和研究问题。冻结训练窗口、重训频率、正则参数、相关阈值、覆盖要求、分块长度、重复次数、随机种子与模型/时间/产物上限。分组沿用源计划的 `mechanism_id`，不根据本轮收益聚类。登记不读取新的收益或输出相关性；历史发布报告已被观察不能恢复密封身份。代码快照记录继承 HEAD 与实际包内容身份。

## 相似性与代表

先核验规范 Spec 身份与账本，保留结构关系；再在发现期共同完整截面逐日计算 Pearson、Spearman、中位绝对 Spearman 和绝对 Spearman 的95分位。常数截面的无定义相关不填零；有效日期不足失败。共同股票池必须满足事前覆盖要求，不同模型不能因可用列减少而扩大股票池。

同机制内以中位绝对 Spearman 达阈值作为替代候选，按发现期原始测量覆盖率、稳定编号顺序选代表。每个替补必须直接满足与代表的阈值，不把相关链的端点误当高相关。无收益的精简名单在读取本轮标签前保存。弱单因子 IC 不作为新的组合资格否决，替补不丧失原资格。

## 模型与交易

原方向因子秩的等权平均为简单对照。每个非空子集分别拟合普通收益预测 Ridge，复用共同训练截面的充分统计量。正则参数事前固定，不做收益驱动调参。按完整市场日历锚定每五交易日信号；训练仅使用标签退出日严格早于预测日的样本，固定 T+1 入场、T+6 标签退出。先形成信号池再左连标签，未来缺失标签不能删除预测证券。评价尾部只接纳固定退出日不晚于评价结束的窗口，不读禁止区间收益。

主对照是所有候选 Ridge 与相关性代表 Ridge；等权排名及无信号全截面等权股票篮子同时报告。多头顶部十分位、统一资金、买不到留现金、卖不掉锁仓并逐日重试，均复用因果成交引擎。子集主成本为买卖合计14bps；四个固定对照另报零成本和20/40bps。成本按真实订单重算，不能从年化结果加减。Top−Bottom 不作为可交易利润。

未确定终值时保留订单、选择、未确定持仓、最后报价参考和零回收情景；实际指标保持空值。共享模型面板与逐次拟合权重可重建全部子集预测；每个子集保存训练审计、日收益和订单，可按选择与成交重建持仓，不复制全套预测及日持仓矩阵。参考情景用于本轮贡献诊断，不能冒充实际净收益归因。阶段边界同时检查至少256MiB可用磁盘，避免已知的低磁盘空间导致整轮写盘失败。

## 删除与归因

逐因子与逐机制组删除后重训，删除损失为全部组合 Sharpe 减子集 Sharpe。小权重、接近零损失不直接淘汰输入，避免将互相替代的因子同时移除。

组 Shapley 的价值函数为每个子集重训并按统一规则交易所得的参考净 Sharpe。空集为共同信号股票池的等权多头基准；不将现金零方差 Sharpe 设为0。精确枚举仅在模型预算内允许，否则冻结随机排列数量与种子，缓存重复子集；全部贡献严格加总为完整模型与空集基准的表现差。

普通收益预测 Ridge 并非 Ridge-SDF；本版也不声称完整复现 SPPC。SDF 原文用管理组合收益回归常数1，包含跨资产联系。本版采用“删除输入后重建策略”的重训子集 Shapley 定义，区别固定模型的信息屏蔽归因。原论文来源：[SDF](https://arxiv.org/abs/2602.20856)、[SPPC](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4628462)。SPPC 全文在首次核验时受访问限制，不能将未核验实现细节写成论文结论。

所有模型共用按日期分块的抽样索引。报告删除损失和 Shapley 的条件分块区间，另报排列近似标准误。分块区间条件于既有预测，未计入历史筛选、重新拟合或多重比较不确定性，不是正式显著性检验。没有按正负 Shapley 自动删除、保证归因排名稳定或预设最终数量的规则。

## 范围与交付

首轮完成全池因子删除及组层 Shapley，不因看到结果而自动展开组内子集搜索。研究结果保留全部指标和证据不足情形，精简比较使用完全相同的日期、股票池、拟合与执行规则；由于候选及历史区间已经参与研究，比较仍是事后诊断。

新增产物写独立目录，生产数据库、原研究账本与 main 工作目录不变。HTML/中文报告展示净值、固定成本对照、删除贡献及组归因。单写入启动、输入/协议/代码变更、预算超限、缺数据和日期不一致均失败；失败不会清除已有尝试或缩减原检验族。模型预算包含所有删除、子集、精简和简单对照。时间与产物在阶段边界核验，可能超出一个阶段；不声称可强制中断单个库操作。模型响应与 Token 计费本入口无法观测，不填零或冒充账户限额。

配置字段和可执行参数示例见 `examples/joint_diagnostic.json`。回归覆盖同类替代、链式相关、Shapley 加总、预算、标签 purge、未来标签不影响预测股票池、协议变更和实际未知终值语义。

## 中断后的有限重放

`replay_from` 可指向已完成或已失败的旧运行，只补完原先冻结的模型清单。原始候选、数据、参数、随机种子、名单与资源上限必须完全一致；模型、统计及成交实现内容必须一致。独立新目录登记已完成成交缓存的全部文件哈希，重新核对拟合权重和日期，随后只读引用缓存。未完成的子集照原规则计算，不重置旧试验或冒充首次观察。旧中断与产物原样保留；源缓存是复现依赖，不得当临时文件清理。缓存不重复计为新产物，但保留继承来源和已完成模型数量。

报告中未提供市场基准的辅助 `information_ratio` 以零收益为参照，不能解释为跑赢市场指数；主要指标为固定252交易日年化的参考 Sharpe 与相同日期配对差。
