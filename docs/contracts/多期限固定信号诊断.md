# 多期限固定信号诊断

用户已允许日频、周频和月频因子研究。第一步固定现有信号、原方向及模型选择边界，比较1、5、20个市场交易日收益；不要求所有机制预测五日收益，也不将这次诊断称为三种调仓策略已经验证。

`factor-miner run-horizon-diagnostics <配置>`先登记期限网格、输入哈希、统计容量、分区和代码快照，再构建新标签。统一日历固定T+1开盘入场，T+2、T+6或T+21开盘退出。端点价格无效或指定方向不可成交时标签为空，不顺延、不删除信号日股票。标签列分别为`label_o2o_1d`、`label_o2o_5d`、`label_o2o_20d`，不能把月度收益塞进名为五日的列。

发现2021—2023、2024验证、2025已消费历史复核的比较分别按标签退出事件purge。每日IC序列对1/5/20日期限使用冻结HAC滞后5/5/20，并继承完整试验族。所有期限与失败一并报告，不读取结果后选择好看的年份或翻转因子方向。五日标签在共同有效样本复现旧价格收益；新的端点可交易与分区边界差异单独计数。

日频、周频、月频调仓需要独立的现金、锁仓、成本、终值和组合增量检验。20个交易日预测不等同于月末调仓；均匀5个交易日也不等同于每周固定日。新增候选、期限变体、联合模型与调仓方案都占事前预算。已有五日FaVOR及旧回测原样保留，未通过因子不能因某一期限IC好就直接加入十五个目标。

新期限沿用原发布的全部标签资格：信号日`valid_for_factor_rank`、入场日`can_open_long`和`valid_for_o2o_label`、退出日`can_close_long`和`valid_for_o2o_label`均须成立。有价格且可成交不能覆盖供应商标签观察隔离。该资格是每日开盘观测的有效性，不代表预测目标只能是五日。首版期限诊断漏掉标签专用资格，保留为失效工程产物；修正后重新登记并回放，旧原八与两组新候选的五日FaVOR和组合对照不受影响。
