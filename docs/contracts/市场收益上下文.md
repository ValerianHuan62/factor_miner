# 市场收益上下文

市场共动风险与个股波动不同。研究可以在冻结的股票 OHLCV 旁附加同日市场价格收益，不能用未来指数收益或期末指数成分股替代当时信息。风险调整收益的论文结论不直接支持五日未调整收益；具体代理、估计窗口和方向必须另行预登记。

`run-research-report` 可显式配置 `market_context_path` 与 `market_context_contract_path`，两个文件都必须列入冻结 `input_sha256`。没有配置时字段白名单保持原 OHLCV。配置后只增加 `market_return`，原股票行、mask、标签、调仓规则与记账口径保持其各自冻结合同。

上下文文件只能含 `date: Date`、`market_return: Float64`，日期必须唯一、非空且精确覆盖原市场日历，值必须有限且非空。合同 `market-context-v1` 必须绑定数据及日历身份，声明 `close_t` 观察、`after_close_t` 可得、`close_t/previous_market_close-1` 计算、`price_return_excluding_dividends` 口径。日历外日期、覆盖不足、缺值、同名字段冲突或哈希变化必须失败，不填零、不顺延。

提供方必须保存版本化来源、指数身份、原始价格快照和同日收益独立验证，确认每个值只用当时收盘与前市场交易日收盘。代码对固定合同的检查不等于验证供应商真实可得时间。供应商历史修订数据不得伪称当日已保存的历史快照。

构念反例保持市场路径和股票原有冲击，增加股票对同期市场的响应；目标相关测量应提高，股份单位重标不应改变结果。这只验证测量，不确认杠杆约束或定价机制。真实发现、确认、去重、增量及成本仍按原流程执行。

极端幅度响应的 `market_curvature` 反例固定同一市场路径，在股票原有简单收益上添加与市场收益平方相关的分量，再重建合法 OHLC。它检验平方响应测量能否识别被加入的变化；未剔除线性市场暴露的平方相关代理不能称为完整条件共偏度估计。股票收益减市场收益后的波动也只能称市场相对波动，不能当作估计了 beta 或多因子模型的残差波动。

`market_delay` 反例保持市场与原股票冲击不变，只在股票简单收益中加入前一市场日收益的正向响应，再重建 OHLC。`rolling_partial_corr` 可以在控制同期市场收益后测量这类延迟响应。市场滞后必须按冻结日历精确对齐，股票缺端点则窗口无效；这一日频、有符号的简化测量不是多个周滞后回归的价格延迟指标复现，也不能区分信息摩擦、陈旧报价和非同步交易。原方向、频率、窗口及这些竞争解释需要在结果前冻结。

`price_updates` 反例保持成交量不变，让收盘报价每五个观察行才更新一次，检查报价更新占比是否降低。这里相邻观察行不一定是相邻市场交易日，缺失行不插入报价，实际缺失值不算平盘。该测量没有估计买卖价差或交易次数，不能称为完整交易成本模型，也不能把未更新的收盘价等同于无成交。

## 市场上涨与下跌的不同响应

`rolling_partial_beta(R, M-abs(M), M, window)` 是带截距、以市场收益零为拐点的连续分段线性回归。其输出b满足上涨斜率c、下跌斜率c+2b，因此b是两段斜率差的一半；不能直接称为下跌样本内单独回归的beta，也不能称为论文按均值划分的条件beta。窗口只有同号市场收益时两个解释变量无法识别，返回null。

合成 `market_downside_asymmetry` 只增加股票在市场下跌日的损失敏感度，目标测量应提高；独立检查增加普通市场beta不影响测量。这些测试确认公式含义，不证明下行风险获得回报补偿。候选须事前冻结方向、窗口和分段模型假设，明确同期解释与未来收益预测的区别。

## 价格冲击代理在坏市场时的变化

股票自身交易困难程度与市场收益的关系，是区别于平均流动性水平的待检验主张。使用 `abs(calendar_delta(C,1))/(calendar_delay(C,1)*C*V)` 表示绝对日价格收益除当天美元成交额，单位为每美元。零成交或缺少指定前一市场日收盘时缺失，不填零。`rolling_partial_beta(该代理, M, abs(M), window)` 只度量控制市场绝对幅度后的有向市场敏感度。

该回归没有估计流动性创新，不可称完整LCAPM或原文AR创新beta。状态持久性、分母的规模效应、微观结构噪声与股份价格复权语义须写入候选限制。合成 `liquidity_bad_market` 固定股票价格、只使市场下跌时成交收缩，价格冲击代理对市场的斜率应下降；真实机制仍需独立报价或订单数据验证。
