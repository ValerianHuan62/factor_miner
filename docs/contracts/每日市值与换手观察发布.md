# 每日市值与换手观察发布

本合同接入已有历史每日市值和同日原始成交字段，供周频研究使用。市值控制规模，成交金额相对市值近似股本换手；它不是自由流通股换手，也不是实际买卖方向。

正式入口为`factor-miner publish-capitalization-release <配置>`。输入显式绑定原始数据与字段映射、基础发布、金额单位、可用时点、年度修订限制和全部文件哈希。供应商每日市值以千美元计，转为美元；价格和成交股数保持同日未复权单位。因子层可计算`成交股数 × 同日价格 / 美元市值`，不能混入拆股调整后的成交股数。市值、价格必须正且有限，成交股数非负且有限；合法零成交保留零，未知不前填。

同键完全一致才合并，冲突硬失败。独立发布严格保留原行情、状态、日历、标签和终止事件；输入及代码快照在运行前后核验。现有标准发布范围不变，不按2026存续证券筛选。

历史观察保守在对应交易日结束后使用，最早下一市场日交易。年度CRSP历史不是逐日原始版本；不能声称有精确公告可得时间，也不能从每日市值变化推断当时已公布融资或回购。仅保留已消费历史研究资格，不自动升级为实盘可用PIT数据。

合成回归检验拆股单位不改变换手、固定股本增加成交提高换手、固定价格路径改变成交收益关联、错误方向拒绝、合法零与缺失分离、千美元转换以及原面板不变。DSL的五层、十五节点限制保持，不新增算子；新增两项合成响应只验证测量，不证明流动性提供的经济机制。

## 可选的规模领先收益上下文

显式开启`include_return_context`时，额外提供同日CRSP价格收益与市值加权市场价格收益。字段映射和指数定义必须冻结。个股收益的前期日期必须是固定前一市场日，非相邻价格期保留空值，当前或未来前期日期拒绝。同日重复证券记录及跨证券市场指数必须一致，指数缺失失败。供应商价格收益不包含普通股息，但不能一概称为排除所有公司行动；它仅作预测输入，原五日开盘价格标签保持不变。

规模领先研究可用控制当期市场收益后的滞后市场暴露，乘已观察的近期市场收益形成条件预测。该输入不是用同期共同市场收益加减后声称产生新的截面排名；它需要证券之间不同的估计响应。回归暴露与条件预测仍保留测量、经济机制及可交易贡献三层结论。
