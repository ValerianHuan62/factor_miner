# 组合研究池与有限机制预算

2026年9月10日补充：新增 A 股与美股信号探索采用[跨市场探索入口与确认分层](跨市场探索入口与确认分层.md)的版本化入口和 `signal_exploration` 预算目标；本文件原有联合确认或历史研究池规则继续约束其原版本，不自动套用为探索准入，也不改写旧结果。

## 研究目的与结论

独立单因子显著性、组合研究输入资格、条件预测贡献与可交易收益是四项不同结论。组合研究池不以旧 Bonferroni 失败自动拒绝输入，也不把恢复研究资格称为单因子通过。旧方向、公式、检验族、原报告和全部失败记录保持不变。

历史重新分层使用 `research-pool-v1` 独立产物，标记 `test_consumed=true`、`sealed_oos=false`。旧确认区间已被研究者观察，严格走步训练不能消除这一历史选择偏差。新结果只用于探索性研究。

## 研究输入资格

必须通过原构念基础检验、发现期覆盖率至少80%、发现期原方向 RankIC 大于零。没有0.01的边际效应门槛，也不要求边际显著性；不得翻转原方向。所有语义待补证和测量合同否决继续有效。缺失指标硬失败。

资格判断不读取确认期收益或统计。历史公式仍使用同一冻结数据发布、原119观察预热和原时点语义。已归档矩阵写入新的恢复目录，不覆盖旧目录；恢复后必须复现原发现期 IC、RankIC、HAC t 和覆盖率。

## 两种查重

全历史身份、失败原因、公式变体及历史相似关系继续保留，不能因为旧候选失败就重新当作从未试验过。组合冗余只相对本次明确选中的有效代表判断，不能将已淘汰候选作为有效替代品。

先冻结已有组合代表，新增候选按发现期绝对 HAC t 和编号排序。使用发现期逐日真实重叠截面的绝对 Spearman 95分位，至少60日、每日20只证券；达到0.75或规范 AST 相同则作为该有效代表的替补。重叠不足硬失败。停止于已证明高相关的配对时，不宣称其他配对已计算。机制类别相同不自动表示输出重复，类别元信息也不冒充独立机制验证。

## 组合评价

名单在新组合结果揭晓前冻结，只使用发现期选择。模型沿用156周训练、1周隔离、每4周重训、固定 Ridge alpha=10；标签退出必须早于预测日。共同股票池只由当时信号完整性形成，缺未来标签的预测仍保留。

在同一共同股票池比较既有代表组合与扩展组合，并固定执行新增代表逐项移除诊断。所有模型及比较计入预留模型预算；不按照确认结果反复搜索模型或窗口。模型系数属于训练结果，不改写原假设方向。必须单列系数方向冲突，不能凭反向系数宣布原机制通过。

保留原单因子统计闸门。新增模型诊断校正至少继承当前11901倍预算并加本次预留模型数；这是保守的探索性诊断，不声称适应性历史上的正式错误率控制。保留研究输入不要求其本次增量显著；若增量不稳定或负，必须明确显示，不能标成组合贡献已验证。

组合沿用前10%等权多头、固定T+1至T+6、买不到留现金、卖不掉锁仓重试，比较10/20/40bps双边成本。未知终值实际收益保持空，参考报价与零回收分列。成本后收益及风险用于评价策略，不靠更高 IC 宣布盈利。

## 有限信息来源与机制预算

新搜索必须先登记有限候选数、有限模型数、终止条件、每种信息来源和机制配额、数据是否可用及持有期依据。失败、重复、窗口变体、编译失败都消费名额；行政批次号不进入校正公式。预算继承全部历史试验与既有诊断倍数，不能另建目录重置。

某机制没有可用数据或持有期依据时不得登记；不能用另一个价量变体补位并称为新信息。`validate-search-budget` CLI 验证输入清单；历史96候选的本次复核不生成新的因子公式，也不恢复此前无限续跑。

## 展示与复现

旧统计留库表保留原语义；研究池用独立资格字段和投影展示，不能把旧统计失败写成统计通过。Dashboard 必须分别显示原结论和组合研究资格。

```bash
factor-miner run-research-pool <冻结全历史复核配置>
factor-miner validate-search-budget <有限机制预算与已登记尝试>
factor-miner run-ridge-strategy <绑定研究名单的冻结组合配置>
```

回归覆盖弱信号准入、反方向拒绝、原统计不变、失败代表不阻断、有效代表去重、历史预算不缩减以及未来标签污染攻击。

## 预留的弱信号组合对照

联合事件容量不足只否定对应的 FaVOR 联合触发可行性，不自动证明每个构念信号没有组合信息。只有在收益揭晓前另行预留了组合比较时，才能继续独立诊断；正式 FaVOR 资格仍保持失败，比较不借用联合触发的通过身份。

`run-reserved-factor-models` 的 `reserved-factor-models-v2` 合同支持五日目标和156周滚动训练。可复用已冻结的原组合周度特征缓存，绑定源协议、数据发布和文件哈希。缓存属于模型预处理层；加入新信号后按当时完整特征及排名状态重建共同股票池，所有模型重新计算共同截面排名，再统一走步拟合。未来标签缺失不删除预测，新增信号不按边际 IC 筛选。保留逐项移除、逐年配对 IC 和系数方向冲突，预测贡献不代替成本和收益归因。
