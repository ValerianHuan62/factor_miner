# 量价正向多头选优

2026年9月12日用户纠正研究目标：挖掘价格与成交量因子，使高分股票组成更好的多头组合；基本面现成字段接入另行处理，不算本轮挖掘成果。最终入库仍由用户确认。

## 假设与输入

只允许当时可得的 open、high、low、close、volume。按现有 `favor-exploration-v1` 先登记假设、Γ、支持条件、预算及方向，再生成公式。所有新候选事前预期原始方向为正，失败不翻号，不通过取负旧因子增加数量。

首轮冻结两类信息延续假设，各三个形成窗口20、60、120日。价格净进展相对日价格变化离散度用于检验有噪声背景下的方向持续性；标准化价格变化与成交量协方差用于检验成交活动是否集中在上涨日。量价代理不能区分真实投资者身份、主动买卖或信息交易，与论文原规格的差异必须明示。

来源为 [连续信息与动量](https://digitalcommons.chapman.edu/business_articles/115/) 和 [动态量价关系](https://www.nber.org/papers/w8312)。它们提供信息延续与反转的可证伪动机，不证明本地A股五日持有一定盈利。合成漂移、固定价格后的成交联动以及股份单位变换检验只检验测量一致性，机制资格保持未验证。

## 多头选优判断

`top-selection-diagnostic-v2` 在结果揭晓前冻结规则：发现期2021—2023年，验证期2024年至2026年6月，原消费记录不改变；双边万14、T+1至T+6开盘，每五个交易日调仓。Top20为主，Top10/50与20/40bps仅作事前诊断。

除既有构念、原方向、冗余与验证期固定组合增量检查外，要求发现和验证的高分十分组均优于其余上半组及动态全市场等权固定标签参考；Top20在两个区间均有正的实际净收益和相对同截面36代表基线的配对日均净收益增量；2021—2025五个完整年份至少三年实际净收益正。全市场等权标签参考不是可交易策略，不能将标签缺失提前用于选股。历史统计预算未知时正式通过保持空值，收益差点估计不等于显著性。

先用信号日信息冻结六候选与36代表的共同完整截面，再计算百分位秩；36秩等权为基线，37秩等权为加入单个候选后的固定组合。缺少经核验的行业、市值历史匹配输入时不宣称独立Alpha。

## 执行与结果

使用 `register-favor`、`favor-request`、`submit-favor`、`run-favor` 和 `run-top-selection`。旧版本结果保持原样。为了节省回测成本，v2在完成信号日选股后，只加载整个研究区间内可能持有证券的全时段价格与状态；证券集合只来自已冻结信号，未来买不到仍留现金，卖不掉仍按原规则重试。合成回归要求裁剪前后订单、持仓、收益及终值结果完全相同。

无基准传入的单次执行不输出冒充基准信息比率的数值；明确的配对净收益差另列。所有失败、重复和未完成预约保留，不因结果弱而继续扩充本轮窗口。输出待审核清单，不自动写入候选库。
