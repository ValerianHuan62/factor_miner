# 回撤后恢复测量

`rolling_drawdown_recovery(x, window)` 对单个证券的完整正值窗口，按时间顺序找出最低谷峰比；谷峰比等于该位置的值除以前缀最大值。最小比值对应最大相对回撤，也对应最大对数回撤。并列时取最近谷底，输出窗口末值除以该谷底值的毛恢复比，无量纲。

窗口有缺失、非有限值或非正值时返回空；若全窗口没有任何回撤，事件谷底不可识别，也返回空。不得把空值填成零恢复。纯下跌且谷底在末端时毛恢复比为1。所有窗口都只含当日及之前的观察行，不补证券日期。

这个测量与现价除以窗口最低价不同：路径50、100、60、80、90的最大回撤谷底是60，恢复比为1.5，不能用早于峰值的最低价50作分母。并列路径100、50、200、100、150取较近谷底100。

最小合成回归以独立逐对枚举、缺失/非正值、证券分组、单位重标、未来扰动和回撤后的独立恢复干预核验。数学测量通过不代表经济机制或收益预测通过。

候选研究参考[Choi作者预印本](https://arxiv.org/abs/1403.8125)：其恢复为最大回撤谷底至期末的对数收益，本算子的毛比率为严格单调等价量。若采用40观察行、五日标签，必须事前说明与原六周形成、六周持有和重叠组合不同，不能声称复现原收益。该文不同版本日期存在页脚差异，应按下载标识记录，不据此冒充期刊最终版。
