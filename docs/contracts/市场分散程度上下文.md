# 市场分散程度上下文

本上下文测量股票总体价格收益相对市场收益的横截面分散变化，供个股历史条件斜率使用。它不是对原始因子做截面排名、标准分或中性化，也不能证明投资者消费风险机制成立。

`dispersion-context-v1` 固定每个市场交易日按精确前一个市场日收盘计算股票价格收益。仅纳入当日可计算且可排名、前一市场日可计算、两个端点价格有限且大于零的股票。状态与价格主键必须完全相同，不能读取未来可交易状态、未来标签或顺延端点。每天将股票收益与显式冻结市场收益之差的绝对值求和，除以 `N-1`，再做相邻市场日的一阶差分。首日缺前收盘而无总体统计，第二日没有前一天分散值，故字段仅在最初两天保留结构性空值；其余每日至少500只股票，不能静默缩小门槛或填零。

来源为 Verousis 与 Voukelatos（2018），[作者机构接受稿](https://repository.essex.ac.uk/24170/1/CSD_wp_4.pdf)，式1定义分散程度，式6控制市场收益估计个股对分散变化的响应。原研究使用CRSP价值加权市场、超额收益、上月不少于15个交易日和随后月度持有；当前研究如采用其他市场指数、价格收益、20完整观察行和五日标签，必须在假设中明确这些偏离，不得称为原论文复现。股票自身也进入总体统计，自身贡献是竞争解释；独立消费与就业机制未验证时维持 `mechanism_unverified`。

`run-research-report` 必须事前冻结 `dispersion_context_path`、`dispersion_context_contract_path`、价格、状态、市场上下文和总体统计文件身份。来源必须与本批股票及市场输入一致。上下文只有 `date: Date` 与 `dispersion_change: Float64`，必须精确覆盖唯一日历，不增加或减少股票行；校验差分与总体统计相同，任何身份变化、非法空值或覆盖冲突硬失败。没有显式上下文时，公式不得引用新字段。历史相关检查必须恢复原候选的上下文身份，不能用后来修改的总体构造替代。

独立验证须用原始证券价格和状态重建日期端点及每日总体，逐日复算绝对偏差总和与差分；再以独立带截距OLS检查候选斜率、完整窗口缺值、股份单位变化及未来值攻击。测量验证和历史预测检验是不同阶段。
