# 滚动样本协方差合同

`rolling_cov(x, y, window)` 是通用类型化原语，返回同一证券、相同完整观察窗口内的样本协方差，固定 `ddof=1`。单位为两个输入单位的乘积，不是无量纲相关系数。复用项目锁定版本的 Polars `rolling_cov`，不增加依赖或放宽复杂度、窗口及可得时点合同。

任一输入在共同窗口内缺失或非有限，该窗口输出为空，不跳过缺失观测，不填零。常数序列的协方差是合法零值，和零方差下不可识别的相关系数不同。禁止centered rolling，窗口仍只允许原白名单。参数数量必须为2，回看为两个输入最大回看加窗口减1。

价格变化的相对自协方差可使用固定市场日历的当前及前期价格变化计算，再除以同期均价平方。该值是有符号统计量，不等于完整的有效买卖价差。正值不截断，也不能解释为负成本。Roll价差解释需要额外模型假设与实际报价数据；合成买卖价回跳只检验公式响应，不证明真实经济机制。

验收包含独立NumPy样本协方差、证券分组、完整共同窗口、无穷和缺失、常数、单位、未来污染攻击及精确市场日历缺口。新构念响应 `bid_ask_bounce` 在相同基础路径上添加交替报价扰动；相对价格自协方差应下降。原始输入、筛选门槛、标签、交易策略与既有算子均保持原合同。
