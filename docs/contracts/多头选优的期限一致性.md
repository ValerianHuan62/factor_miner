# 多头选优的期限一致性

2026年9月13日，用户再次授权量价因子探索，目标为高分多头组合，最终入库由用户确认。新轮须在看到结果前登记持有期，不把中期论文的预测期默认为五日，也不按已见收益挑选最优期限。旧候选、旧方向、已消费样本和历史检验族不改写。

`publish-mapped-history` 的 `mapped-history-v2` 明确支持1、5、20个交易日持有，分别生成固定T+1入场至T+2、T+6、T+21退出的标签。缺报价、不可交易或日历尾部不足仍为空，不顺延端点。旧 `mapped-history-v1` 继续只接受五日。输入发布只读使用，新发布与清单独立保存。

`run-top-selection` 的 `top-selection-diagnostic-v3` 必须显式登记 `holding_sessions`，并与FaVOR计划的期限相同。十分组、全市场标签参考、顶部与36代表组合交易均使用同一期限；旧v1/v2只支持五日，不将其重解释为其他期限。v3沿用v2全部正向多头筛选门槛，未放宽收益、稳定性、冗余或增量要求。

连续信号可每天观察二十日固定标签，IC的HAC跨度至少20；实际交易频率另行事前固定。月末采样与20个交易日持有并不等价于自然月收益；月份长短导致窗口重叠时，现有因果引擎只使用真实可用资金，不能延后买入或提前出售旧批次。测试区间不得因新期限恢复为密封样本外，正式统计通过仍受历史预算缺失限制。

本轮均价偏离代理只借鉴论文的多期限信息和修复动机，不复制其学习权重、多空收益或长期窗口，不宣称文献证明本地固定正向公式有效。
