# 受控研究运行合同

## 适用范围

本合同约束人工或 LLM 候选从提出、批准、计算到发布的完整流程。任何输出都只能称为“通过当前协议验证的候选因子”，不能称为认证 Alpha、因果机制或生产建议。

## 结果揭晓前

1. 登记不可变研究族、候选槽位和全局试验预算。
2. 冻结股票池、标签、观察时点、最早交易时点、预处理、HAC 参数、显著性阈值、Bonferroni 分母和冗余阈值。
3. 标签必须绑定统一交易日历的入场/退出事件日期；相邻分区之间按事件区间 purge，不能只按信号日切割。
4. 每个假设记录主张、机制、方向、代理、独立验证、竞争解释、失效方式、证伪路径和可核验来源。
5. LLM 只接收脱敏简报、字段能力、允许算子和输出 Schema；每次外发绑定精确请求哈希和人工授权。
6. 候选表达式通过字段白名单、类型化 AST、lookback、可得性、未来函数和确定性编译校验后，才允许读取标签或结果。

## 评价与发布

- 成功、失败、重复和未执行槽都保留在冻结研究族中，不补位、不删除。
- 原始 RankIC、方向感知结果、HAC t 值、多重检验、冗余和增量信息必须分别保存。
- 组合必须先用 T 日信息冻结名单和权重，再读取 T+1 及之后的成交状态。T+1 买不到则留现金且不替补、不追单；计划退出日卖不掉则逐交易日重试，未退出资金不得复用；数据终点仍无法退出时 fail closed。
- 交易成本只按真实成交金额计提；订单、每日持仓、拒单和延迟退出次数必须进入审计产物。内部高低极端组差可以用于治理胜率，但不能伪装成公开目标组合。
- 发布前核对数据清单、代码提交、配置、候选、政策、产物文件和运行 manifest 的内容哈希。
- JSON/JSONL 与不可变运行目录是正式事实源；PostgreSQL 仅做幂等投影，失败后可以重试但不能反向修改事实源。

## 失败语义

缺少授权、数据身份、执行状态、标签事件日期、日历、截止日或哈希时必须非零退出。模型响应无效时保留原请求和失败状态；中断恢复只能继续同一不可变身份，不能借恢复重新生成更有利的候选。`dashboard-real-backtest-v1` 和 `standard-panel-v1` 结果只能作为历史审计，不能继续展示为有效回测。

## 精简研究界面与批次登记

Dashboard 只保留看结果、挖因子、设置。默认选择已配置的美股。看结果直接读取当前市场显式回测文件，不依赖数据库成功连接；这不改变完整研究发布仍需 PostgreSQL 投影的合同。主指标保持 IC、RankIC、HAC t 值、年化收益、Sharpe、最大回撤的顺序。实际持仓价值未确定时实际表现缺失；参考估值和零回收压力情景只能在各自标注口径内展示。

新批次使用正式 CLI `factor-miner research start --artifact-root <目录> --requested-at <带时区时间>` 原子登记。相同点击幂等，不同点击在已有待启动批次时拒绝；下一批必须获得新的命令身份。仅登记不能显示为已运行或已完成。控制根由市场的 `research_root` 指定，缺省使用 `artifact_root`；结果目录独立保持只读。

自然语言分区在无活动批次、排队、全部拒绝和完成时均可访问；空白表示没有已登记语义标签，不是盈利机会。后台未连接时必须展示明确状态，不能永久冒充假设生成中。连接后台仍走正式 Worker CLI，并验证控制目录与当前市场数据库环境变量。
