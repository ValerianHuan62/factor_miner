# 收盘报价发布与交易成本量级审计

## 研究用途

收盘买卖报价提供直接报价信息，可以与此前的高低价差代理区别检验。数据接入不等于发现因子；报价覆盖高、与旧因子相关性低，也不能替代构念、方向、组合增量和扣费执行验证。

[CRSP 数据指南](https://www.crsp.org/wp-content/uploads/guides/CRSP_US_Stock_%26_Indexes_Database_Guide_Flat_File_Format_2.0.pdf)定义 `DlyClose` 为常规交易时段的最后成交价，`DlyBid`、`DlyAsk` 为交易日记录的收盘买卖报价。最后成交与报价未必同步，不能把两者的位置关系直接解释为订单失衡或实际成交方向。

## 独立发布

`publish-quote-release` 接受显式来源、字段映射、证券前缀、数据单位、截止日及输入哈希。核心不依赖某个私人数据库或目录。新面板只增加 `quote_bid_raw`、`quote_ask_raw`、`quote_close_raw` 及有效状态；原股票池、复权行情、日历、三类资格、标签及终止事件均保留。

同一证券日期的重复报价字段完全相同才合并，冲突硬失败。买卖报价非有限、非正或倒挂时标为不可用并置为结构性空值；缺失不前填。相等报价保留为零价差，但相对价差内位置不可计算。最后成交价独立检查为正且有限；不强制它处于收盘买卖报价之间。

报价字段是同日未复权美元价格，不能直接与面板复权 `close` 混算价差或跨拆股比较原始报价。后续假设应先用同日三项报价构造无量纲测量，再应用登记的滚动算子，Γ 必须约束价格口径。不得把历史年度数据库当成逐日归档版本，也不得把股本的历史生效日期当成公开披露时间。

发布在新目录登记全部输入与代码，核验基础清单及日历、状态身份；完成时验证原行情精确一致、其余文件逐字节复制及输入未变。错误保留失败产物，不覆盖旧发布。

## 既有订单成本审计

`audit-quote-costs` 读取冻结的实际成交清单，仅纳入已成交买卖单。按实际成交日前一个**市场交易日**连接收盘报价；节假日不按自然日回退，前一交易日缺报价则保持未知，不跨缺口寻找更旧报价。

半价差为 `(ask - bid) / (ask + bid)`。按实际成交名义金额加权，分别报告年度平均半价差、超过固定单边成本的成交金额比例，以及报价缺失的金额与覆盖率。缺失部分不赋零成本。10bps 单边对应 20bps 完整双边。

这是成本量级诊断，不能把收盘报价当成次日开盘集合竞价价差。它不修改订单、持仓、现金或净值，不从既有收益直接扣除所谓“额外价差”。若量级明显不匹配，需要另行事前冻结可追溯的执行敏感性情景，再完整运行资金与订单模拟。冲击、费用和有效价差仍需分别处理。

## 正式入口与验证

```bash
factor-miner publish-quote-release <报价发布配置>
factor-miner audit-quote-costs <冻结订单审计配置>
```

合成回归覆盖同键冲突、倒挂与零价差、节假日前日连接、当前日报价污染、缺报价不补齐、名义金额覆盖分母、原输入不变及发布不可覆盖。
