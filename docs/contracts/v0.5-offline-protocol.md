# V0.5 离线协议运行合同

## 1. 金融研究边界

V0.5 离线核心只冻结“研究什么、生成了什么、何时可以看结果”。它不连接外部大语言模型，不读取真实行情或标签，也不产生候选有效、机制成立或可实盘的结论。

覆盖图谱用于发现研究方向，因此图谱使用的历史信息与候选评价数据必须分别登记。若两者重叠，后续结果只能称为探索性筛选；HAC 与 Bonferroni 不能消除覆盖图谱形成过程带来的上游选择偏差。

## 2. 严格时间留出

`strict_temporal_holdout` 不比较候选生成时间，而比较原始数据依赖：

```text
全部已封存有效候选的最早原始观测
  >
discovery context 的最晚信息时点
```

候选的最早原始观测同时包含：

- 因子 AST 回看窗口实际读取的最早行情或基本面观测；
- 标签计算实际读取的原始交易日；
- 五日标签跨越图谱 `visible_end` 后形成的信息；
- 形成图谱时使用的派生统计和状态快照信息。

任一候选跨界时，预登记为严格时间留出的 family 必须硬失败，不能自动降级。需要复用 discovery 数据时，必须在结果打开前登记为 `reused_discovery_data`。

## 3. 120 槽与不可逆封存

发现研究族固定四个 arm，每个 arm 30 个候选槽，总统计预算为 120。拒绝、重复、非法、生成失败和基础设施终止都保留明确终态，不允许补抽。

只有全部 120 槽进入不可变终态，系统才能生成 `generation_seal`。seal 绑定：

- family、四个 arm 和两个 LLM campaign 身份；
- 120 槽终态及其对象或终止记录 hash；
- prompt、模型和确定性生成器身份；
- discovery 与 evaluation 数据身份；
- 原始依赖区间、评价政策和 120 槽统计预算。

seal 后任何槽位增删、替换、状态逆转或历史事件篡改都会导致核验失败。在完整事件链、seal 和时间身份全部通过前，结果端口不得被调用。

## 4. 隐私与外发

绝对路径、IP、个人身份、密钥、真实因子身份、原始行情、完整 IC 和能够反推内部结果的内容绝对禁止外发。聚合 coverage gap、失败类型、字段能力和表现分箱只有在公司政策逐类允许后才能进入预览。

外发预览对最终规范 JSON 字节计算 SHA-256。任何字节、模型、prompt、预算或 endpoint 变化都会使后续授权失效。离线核心不读取 `DEEPSEEK_API_KEY`，也没有 HTTP 或文献网络代码。

## 5. 当前命令

```bash
factor-miner llm brief-build-synthetic <input.json> --artifact-root <root> --synthetic
factor-miner llm family-register <family.json> --artifact-root <root>
factor-miner llm event-append <event.json> --artifact-root <root>
factor-miner llm family-seal <family_id> <seal-input.json> --artifact-root <root>
factor-miner llm family-verify <family_id> --artifact-root <root>
```

这些命令不提供跳过隐私、跳过 seal、强制 strict、读取 outcome、覆盖 endpoint 或传入 API Key 的开关。

## 6. 运行环境

Mac 只允许运行程序生成的纯合成测试。公司 Linux 必须使用锁定提交和 `uv.lock` 重跑完整离线套件。真实图谱、外部模型调用、人工外发授权、候选编译和真实评价属于后续受控在线阶段。
