# 十二因子状态假设比较

## 研究问题

应用户要求，将一次单因子案例扩展为12个既有因子的比较。研究状态假设、弱化与失效条件，以及分条件使用相对始终使用的预测增量；不复现 BTQ，不修改默认筛选或旧候选资格。原单因子结果单独保留，huan007 标记已查看，并报告剔除它后的整体统计。

## 事前名单与状态

按原机制选取四个家族各三个已有因子，不按本轮收益选择。每个因子保留原方向，只用一个状态，新增适用状态和失效条件在配置中与原假设分别保存。

| 机制家族 | 因子 | 预期增强状态 |
|---|---|---|
| 临时需求与反转 | huan007、huan075、huan089 | 高市场报价价差压力 |
| 风险与不确定性 | huan029、huan044、huan055 | 高市场波动 |
| 趋势与信息传播 | huan037、huan042、huan059 | 高市场路径持续性 |
| 彩票偏好与过度追逐 | huan027、huan052、huan073 | 高市场相对交易活跃 |

状态定义为：前轮已冻结的20日市场中位报价价差；当时可排名股票等权市场收益的20日标准差；20日市场收益和绝对值除以绝对收益和；个股5日相对60日美元成交额的截面中位数。每个状态均滞后一个市场日，超过此前252个观察的中位数为高状态。窗口和阈值固定，不搜索。行情连续性用市场日历，覆盖不足80%不补值。状态是市场层面代理，不构成投资者行为或因果机制的直接观察。

## 分区、比较与统计

沿用原28因子完整值共同股票池、原周度信号与T+1至T+6开盘标签。2021—2023作为开发描述，2024—2025作为历史复核，最晚信号2025-12-12。开发区间按标签退出事件purge。全部历史已消费，不能恢复密封样本外资格。

逐因子比较适用状态、其余状态、全状态和适用减其余的平均RankIC，各分区每种状态至少26个有效周。按完整周网格执行5阶Bartlett HAC；未来缺失标签不改变选股分组。各年度并列描述。弱状态出现负平均IC只是失效迹象，不能把不显著当成经济效应为零；在适用状态仍非正或状态差异反向，分别保留反例。

主要方法比较：12个原方向秩分数始终等权，与仅给当前处于预期状态的因子等权。权重只由当时状态决定，不依据本轮收益选子集。状态未知或全部不激活则不产生条件预测；RankIC不填零。比较双方有预测的相同日期和股票池，单列停用周，不能把停用造成的样本变化当成全期收益提升。本轮评估预测，不模拟成本后资金账户。

整体状态差异先在机制家族内等权，再对家族等权。使用同一日期上联合影响函数计算HAC，保留因子同期相关和时间依赖，不把12个相关因子当作独立重复试验。全部12个及剔除前轮已见huan007的11个分别统计，不根据结果换名单。

预留12×8项单因子统计、2×2项整体状态差异、2×3项组合比较，共106项，继承至少16125，完整分母16231。若当前登记预算更高须继承更高值。原始p、置信区间与Bonferroni诊断并列；历史适应性不能由校正消除。

## 执行与交付

独立CLI：`factor-miner run-state-hypothesis-batch CONFIG_PATH`。先冻结输入身份、代码、名单、原方向、状态、失效条件和预算，再读取新比较结果。输入只读，输出新目录；失败记录保留。复用原周面板和前轮价差状态，不复制大行情，不自动续跑。

输出12张假设卡、每日状态和覆盖率、逐因子周度与年度指标、完整统计、整体联合推断、组合配对结果、中文报告及哈希完成回执。原始假设与本轮追加命题分列。4个家族、12个因子仍不是全体因子的随机样本，结论只覆盖此冻结集合与历史区间。

验证包括负方向正确使用、状态未知和零激活不生成假信号、未来数据不改变既有状态、日历缺口不顺延、重复因子不能缩小整体标准误、HAC与独立实现一致，以及原单因子时点和标签回归继续通过。
