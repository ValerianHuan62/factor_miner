# 滚动残差波动

`rolling_residual_std(y, x, window)` 在每个证券的同一完整观察窗口内，以截距和x解释y，返回回归残差的样本标准差。分母为window-1，含义是残差序列的样本标准差，不是除以window-2的回归残差标准误；单位与y相同。先对x和y去均值，再投影计算残差，不使用大数方差相减后裁剪负值，也不加epsilon。

窗口不足、任一输入非有限或x恒定而斜率不可识别时返回空值。y恒定且x可识别时允许真实零残差。窗口按观察行，精确市场日收益需在输入端使用calendar_delay。算子不能跨证券、居中、读取未来或在原始层作截面中性化。

将该算子用于股票收益与单一市场指数时，应称市场回归剩余波动，不能直接称FF-3特质波动或完全剔除系统风险。Ang等（2006）[期刊原文](https://onlinelibrary.wiley.com/doi/10.1111/j.1540-6261.2006.00836.x)的式8包含市场、规模和价值，本项目若只有市场控制，必须明确这一偏离。负向历史关系在原文也是经验难题，不能用显著性冒充已验证经济机制。

验证使用独立带截距最小二乘、完整和缺失窗口、常数解释变量、零残差、证券隔离、纯市场暴露变化、残余噪声缩放、股份单位重标与未来值攻击；已完成批次保留自身代码快照。
