# 单因子状态假设小实验

## 研究范围

按本次用户要求，只借鉴《Quantity, Risk, and Return》的状态假设与条件筛选思想，不复现资金流数量或 BTQ，不把它加入默认筛选规则。不生成新因子，不修改既有方向、候选身份、筛选结论、账本或数据库。

选择已有美股 huan007（1日反转），依据其原假设已经要求按流动性、价差检验，而非依据本次条件收益。此次新增假设为：市场报价价差压力高时，原方向五日预测作用更强。这一状态命题在本次结果前冻结，但原样本已用于历史研究，不能称作完全事前发现。

## 固定输入与状态

复用既有28因子共同股票池的周度分数，仅读取 huan007。采用显式冻结的历史报价发布、可排名状态和市场日历；独立输出目录绑定全部输入哈希、候选原报告与实现快照。

每日以全部当时可排名证券计算有效相对收盘报价价差 `2*(ask-bid)/(ask+bid)` 的截面中位数。无效报价不补零，有效覆盖至少80%。市场压力为连续20个市场日的中位价差均值，信号日滞后一个交易日；高压力定义为超过此前252个压力观察的中位数，其余为低压力。窗口、阈值和方向不优化。

状态是市场层面的时间分组，不乘进因子分数，不按未来标签重新确定股票池。历史报价发布没有逐日原始存档保证；此状态也可能反映股票组成、价格水平等竞争解释。

## 固定比较与统计

开发期2021—2023年，历史复核2024—2025年，最晚信号日2025-12-12。标签沿用固定T+1至T+6开盘收益；开发期标签退出不早于复核起点时 purge。保留没有可用标签的原信号、证券分组和日期。每日有效标签至少20只、覆盖至少80%才计算RankIC。

主要比较是历史复核期的高压力减低压力平均RankIC。两分区分别计算全状态、高压力、低压力和高减低共8项统计，完整继承当前已登记诊断预算。使用完整周网格上5阶Bartlett HAC与双侧正态近似；缺失周的估计方程贡献为零，不压缩时间距离。每种状态至少26个有效周，少于门槛只记录证据不足。

条件筛选需高压力平均RankIC为正，且高减低差异为正，两项Bonferroni诊断p均小于0.05。校正只作保守历史诊断，不宣称消除适应性历史偏差。2024和2025年并列描述，不选较好的年份。状态筛选未支持不改写原因子单独结论。

同时描述信号先分组的前后十分位五日标签均值之差，缺标签只从均值中排除，报告覆盖。这是毛收益诊断，未模拟成本、未成交、借券和未确定终值，不称可交易策略收益。一个因子的实验不足以证明整套筛选方法优越，也不构成独立因果机制认证。

## 执行与停止

正式独立入口：`factor-miner run-state-hypothesis-pilot CONFIG_PATH`。本轮只运行一个因子、一个状态、两个固定分区，不新增阈值或翻方向。输出先登记、再查状态可行性，最后才读取收益；失败保留记录，结果不得覆盖。

交付包括冻结协议、状态覆盖、每日状态、逐周指标、年度描述、HAC比较、中文报告与完成回执。合成回归验证报价时点、日历缺口、事件purge、标签缺失不改变选股分组、HAC差异与独立参考一致；不触发默认流程或自动跟踪。
