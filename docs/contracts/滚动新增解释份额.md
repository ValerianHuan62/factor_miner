# 滚动新增解释份额

`rolling_explained_increment(y, x0, x1, ..., window)` 接受一个被解释变量、一个基准解释变量以及一至四个新增解释变量。在完全相同的窗口和观察行中比较两个带截距OLS：基准模型只有x0，全模型含全部x。结果为 `(R2_full-R2_base)/R2_full`，是新增解释在全部解释中的比例，不是通常以剩余方差为分母的partial R2。

实现用去均值后的正交投影，并将x0放在首列。新增投影平方和除以全部投影平方和，保证非负，不使用负方差裁剪或epsilon。列尺度归一只是数值求解步骤，不是对原始股票截面作标准化。全部输入必须有限，解释变量满秩，归一设计矩阵最小/最大奇异值比的平方大于1e-12，且全模型R2大于1e-12；否则不可识别并返回空值。股票常数的R2未定义，不能冒充零。窗口观察数必须大于解释变量数，单位无量纲。

用于市场收益及其历史滞后时可构造价格延迟代理。Hou与Moskowitz（2005）原文式2使用一年周度数据、四周滞后、CRSP市场并在持有前跳过至少一月。本项目如采用60完整日观察、四日滞后及下一日开盘的五日持有，必须明确这是迁移假设，不是原文完整复现。日频微观结构干扰、同窗R2的样本内拟合和缺失证券日导致可计算覆盖变化都是测量边界。

独立验证必须分别拟合两套带截距OLS，核对R2比例；检查解释变量秩亏、常数y、单位重标、缺值配对、跨证券隔离及未来值攻击。生产输入的滞后需用显式市场日历，不加未来市场收益，即使文献稳健性部分使用它们。
