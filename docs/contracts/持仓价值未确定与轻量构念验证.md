# 持仓价值未确定与轻量构念验证

## 结果查看与新批次配置

Dashboard 默认展示最后报价参考估值表现，实际回收缺失继续保留在正式产物中。未确定持仓及原因放在展开说明，主页面直接显示有明确估值口径的年化、Sharpe、回撤。日期区间、往返成本和额外往返滑点共同作用于卡片与曲线；成本敏感性保持原成交路径，基准沿用已发布成本，不等同于重新模拟现金约束。零回收压力只在原报告末日发生，截取更早区间不会提前强制清算。

`run-research-report` 支持显式 `family_size`、`rebalance_frequency`、`ic_frequency`、`max_abs_output_correlation`、`input_sha256` 和冻结历史库。新研究先登记 CandidateSpec 与 CampaignSpec，再读数据和标签；名额不得少于登记候选，失败事件保留在 JSONL。周频采用完整市场日历的一周最后交易日，不因区间截止日位于周中就提前生成信号。未设置频率的旧报告保留原来的日频 IC 与每五交易日调仓规则。

轻量构念测试可以事前选择成交量增长、成交额不稳定、隔夜跳空、收盘位置、上行或下行尾部、振幅不稳定、量价联动和流动性干预。`absolute_return_volume_coupling` 保持价格路径不变，仅让成交量与绝对收益同步；`range_persistence` 保持每100日振幅比率分布及开收盘路径，重排振幅的时间顺序，以检查序列持续性。测试仅改变合成观察条件，不能读取收益标签、根据真实收益更换条件或宣称已经验证经济机制。涉及比率的反例必须检查是否同时改变分子和分母；未隔离目标的失败反例不能独自证明公式错误。

周频固定五日持有期可能因节假日产生窗口重叠或间隔。执行器仅在显式启用 `allow_noncontiguous_schedule` 时接受此类日程：每笔持仓按原计划退出，资金在退出前锁定；新订单按可用现金同比例缩减，资金不足的订单当次拒绝，不在资金释放后顺延买入。默认首尾相接合同保留。

`run-incremental-report` 使用事前冻结的完整美股历史基底，与基底逐一加入发现期合格新候选比较。模型只使用过去窗口、冻结 Ridge 强度和重训频率，并按标签退出事件 purge。截面特征先按信号日构建，再左连事后标签，不能按未来标签可用性删除预测对象。缺失特征使用共同完整交集，不填零。输出条件 RankIC 及相对基准增量；这些统计不能直接当作可成交策略表现。

## 批准范围

用户于本对话明确批准：已有退市依据按实际记录结算；行情消失且没有结算依据的已成交持仓保留为价值未确定；增加全部零回收压力情景；接入轻量构念验证并将全部原候选展示到 Dashboard。无需补取数据，也不允许事后删除这些亏损或未确定交易。

## 记账与回测

核心 `simulate_causal_extreme_portfolio` 新增 `report_unresolved` 模式。原 `fail_closed` 默认保持。终止数据必须由市场适配器转换为与持股单位一致的 `terminal_value`，记录事件日、可得日、来源。

日级可得日保守解释为当日收盘后，事件及可得日之后的下一交易日才结算并允许使用现金。CRSP 终止收益乘以事件前最后有效拆股复权收盘价；官方现金并购金额转换到相同股份单位。终止结算不伪装成市场卖单，不收取普通买卖的成交成本。

T 日仅使用当时因子与排名资格冻结选股；T+1 不成交留现金，不替换；退出失败逐日重试。报告模式的所有账户持续到共同数据末日。没有可核实终止价值时不生成卖单或回收金额。

参考净值沿用最后有合法报价的开盘价对锁定持仓估值，不能称为真实可回收净值。未确定列表保留证券主键、买入日、计划退出日、股数、最后可用报价及日期、参考金额，真实回收值为 NULL。此资金不回到现金账户。零回收压力情景只在报告末日写减未确定持仓参考价值，不影响此前交易。基准采用相同情景。结果包含现金、未确定参考金额及已结算终止笔数。

成本为双边 10bps，单边 5bps；日换手记录买卖双边总金额，情景工具必须按该定义除以 2，不能重复加倍成本。调整费用的 UI 为固定历史交易路径的事后敏感性观察，不是重新模拟资金约束。

## 构念验证

`PredictionProposal.observable_condition` 在生成公式之前冻结观察条件、测量对象、股份单位不变性、支持的合成反例和响应方向。通过 provenance 进入不可变候选。旧假设缺少该字段时不改变原内容身份，并报告证据不足。

标准 trusted workflow 在打开标签之前写入 `construct_validation.json`。本次报告 CLI 另外计算训练期的五分位当期市场统计，不使用未来收益作构念检验。股份单位重标保持美元成交额；价格乘 10、股数成交量除以 10，检查测量是否改变。趋势、波动、反转与相对振幅反例检查事前响应。

结果为“偏离”“基础检验符合”“证据不足”。只有尺度检验时不能判定总体构念符合；全部保留 `mechanism_unverified`。当前原 30 个候选的合同属于事后审计，不声称新预登记；它们不会因检验结果被改写或删除。本次没有额外调用付费 LLM，解释来自确定性检验记录；新 LLM 假设请求已包含观察合同要求。

## 发布与展示

正式入口为 `factor-miner run-research-report <配置.json>`。该报告流程完成原始计算、构念审计、事件 purge、发现方向冻结、确认 IC/HAC/30槽 Bonferroni、发现期两两输出冗余及两个极端组的因果记账。统计通过与构念一致、最终实际投资表现分别展示，不能混为单个通过状态。

数据、配置、代码快照、候选登记账本和 JSON/Parquet 运行产物为可复现依据。旧产物不覆盖。数据版本使用 canonical release ID，不计算数据文件 SHA256。

`python -m dashboard.publish_research_report <报告目录>` 在美股库单事务写入 `factor_miner_internal.causal_reports`，保留历史指标并核对原 `huanNNN`。用户维护的 `factors` 与 `factor_metrics` 字段结构及非空约束保持。旧 `factor_metrics` 整行及 evaluated_at 保留为历史结果；Dashboard 从侧表读取本次 IC 和记账报告，存在未确定持仓时展示的实际投资表现字段为 None，原因通过状态与完整报告展示；压力情景指标不填入这些字段。

Dashboard 回测页提供持仓明细、终止结算、基准未确定持仓、估值情景切换、构念反例与训练期分组统计。所有确认日期已经消费，不是新的密封样本外结论。

## 数据质量附录

报告流程增加独立的相邻可见报价连续性检查：复权开盘价比值 >10 或 <0.1 时留存全部证据（包括长缺口），仅作核查警报，不自动删样本或推断公司行动。报告级 `data_quality_audit.json` 及 PostgreSQL `factor_miner_internal.run_quality_audits` 保存该结论。存在未解释断点时，因子探索和回测系统显示数据待核，所有收益和 IC 仅供诊断；零回收压力情景不能修复此前的错误报价。

修复数据接入后升级为 `price-continuity-l2-reviewed-v2`：开盘、收盘分别检查 >5 或 <0.2，相邻正报价跳过缺价但不补价。逐事件连接 L2 的计算、排名、开仓、平仓及标签资格；已隔离坏价不再误判为可用数据失败。真实暴跌只能按发布内裁决的具体证券、日期、报价比例（0.5% 容差）豁免。仍存在可用未裁决断点时报告 CLI 停止，不进入因子确认。旧报告不改写。

简单策略是单独的工程验证对象：发现期筛最多三个不同假设，要求构念基础符合、原假设方向一致、绝对 RankIC≥0.01、覆盖率≥0.8、Bonferroni p<0.05、非冗余。按发现期绝对 HAC t 排序，规则与入选因子均在打开本轮确认结果前冻结。有向截面排名等权平均，前10%等权多头；无合格候选就不强行构造策略。组合不分配 huan 因子编号，不以确认结果调参，也不声称是新统计通过因子。
