# 滚动左尾同步数据合同

`rolling_lower_tail_overlap(x,y,window)` 使用同一证券、同一完整有限窗口，分别找到x与y最小的 `ceil(window/20)` 个观察，计算两组日期交集数量除以该数量。比例固定5%，120观察窗口中各取6个日子。两组尾部边界必须唯一，即第6小严格小于第7小；边界并列、常数或缺失窗口返回空，禁止用日期或随机数打破并列。尾部集合内部的并列不影响唯一边界。

该量是有限阈值的经验同步频率，处于0至1之间。它不是极限下尾依赖系数，也不是拟合Copula后的系数，不应沿用原论文的独立风险定价结论。120观察只有6个尾部事件，估计粗糙；冻结该取值后不因结果不佳而调整比例或窗口。

原始测量仅用个股时间序列和同日市场收益，不做横截面排名。收益按精确上一市场日计算，缺日不顺延。独立排序和集合交集核对生产partition测量；检验单调变换、未来、多证券、并列及严重损失日期对齐响应。合成响应不证明真实市场存在崩盘风险溢价。
