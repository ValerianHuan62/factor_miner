# 有限研究与资源复用

2026年9月10日补充：新增 A 股与美股信号探索采用[跨市场探索入口与确认分层](跨市场探索入口与确认分层.md)的版本化入口和 `signal_exploration` 预算目标；本文件原有联合确认或历史研究池规则继续约束其原版本，不自动套用为探索准入，也不改写旧结果。

## 研究目标与适用范围

后续研究以一个明确的组合短板和一项主要比较为单位，不以凑足固定因子数量作为自动续跑条件。没有新增认识、本轮结束、资源达到上限或必要条件失败时停止，不自动扩展机制、窗口、模型或成本场景。恢复研究仍以用户当前任务范围为准；工程修改不启动真实挖掘。

本合同只约束新运行。旧计划、公式、方向、试验历史、校正分母、已消费日期和结果不修改。数据因果性、状态掩码、缺失值、标签事件 purge、成本和未确定终值仍是硬约束。可行性失败不是收益失败，通过可行性也不是 Alpha 证明。

## 先检查能否完成检验

`preflight-favor` 保留原合成测量检查；增加 `--with-data` 时核验冻结行情、状态、日历哈希，只计算发现期及预热数据，不读取收益标签。输出每个事前状态锚的覆盖率及各条件首个状态锚的三档联合事件数量上限；这些是代理提示，不代表尚未生成的候选。

新增真实 `register-favor` 自动执行上述检查。测量合同不自洽时拒绝登记。状态锚覆盖不足或事件数量不足时，必须在预算的 `feasibility_response` 写明代理与预计候选的差异及为何仍有必要研究，否则拒绝登记。解释不是豁免正式候选门槛；仅能说明为什么事前代理提示不能直接否定候选。不得用事后收益修正解释或挑选适用股票池。

候选提交后，新预算运行先检查真实候选覆盖及有效截面日期，再做五分位测量；全部完整组合均无法达到冻结的事件支持门槛时，保留候选、构造结果与全部名额并直接收尾，不读取收益标签、不训练模型、不跑交易。事件预检不使用未来收益是否存在或是否为零，得到的是乐观上限；标签缺失及 purge 只能进一步降低支持。

## 区分验证对象

预算的 `validation_target` 必须明确为 `joint_trigger` 或 `portfolio_increment`。FaVOR 只接受前者，继续执行五分位、AND 和 q50/q70/q90 三档选择性；普通组合增量对照使用现有冻结组合入口，不能把 Ridge 结果冒充 FaVOR 通过。该字段不额外授权生成新候选或绕过跨市场新假设合同。

状态锚与因子使用相同表达式，最多说明测量定义自洽，不证明独立经济机制。适用证券范围须事前以可得信息定义，覆盖率和基准使用同一范围，不把未知填成零，也不依据收益删股票。历史年份是否可用于新验证以使用记录为准。

本次不调整 80% 覆盖、50% 事件支持或 Bonferroni 分母。改良检验族、适用范围或统计功效需要新协议，不能让旧失败借新门槛升级。

## 预算与停止

新真实 FaVOR 登记要求 `search_budget.version=bounded-research-v2`，保留候选、模型、机制配额和全部历史预算，并要求：

- `research_question`：本轮回答的金融问题。
- `primary_comparison`：事前指定的主要组合比较。
- `information_gain_rationale`：相对既有信号新增什么信息。
- `validation_target`：联合触发或组合增量。
- `stop_rule`：何时结束本轮，而不是下一轮的自动启动条件。
- `resource_limits`：`model_responses`、`wall_seconds`、`artifact_bytes` 为正整数上限；`output_tokens` 为正整数，或在用户明确关闭输出 Token 限量时设为 `null`。

`output_tokens=null` 表示不因输出 Token 用量停止，返回的剩余额度也为 `null`；实际用量继续记录，未知仍不得填零。其他资源上限及候选、模型、统计预算不受影响。旧计划不改写，此选择在新计划中事前冻结。

用户明确授权连续研究时，可在一轮结束后选择另一个有论文依据、数据支持的问题，再独立登记下一轮；不因单轮结束反复索要相同授权。不得追加已冻结轮次的窗口或删除失败，数据不支持则换假设，不将连续研究解释为无限扩展同一机制的统计预算。

`validate-search-budget` 接受既有 `plan`、`proposals`，另可提供 `usage`，其四个字段必须是同单位的累计已用量。任一用量达到上限，输出 `may_continue=false` 并以非零状态退出。缺失计量不得填写零。资源上限与显著性校正不同，资源不足停止后，失败及未执行预约仍保留，不缩小统计检验族。

FaVOR 在候选、联合组合及收尾阶段边界检查当前执行耗时和本运行新增文件大小。链接的上游和共享代码不重复计入本运行字节数；共享存储需要单独计量。检查是阶段边界停止，不能中断单个正在运行的 Polars 操作，可能有一个阶段的超额。它也不是跨进程总耗时或全盘配额。

核心包无法读取 Codex 会话计费。模型响应数、输出 Token 和跨步骤累计时间由调用方计量并提交 CLI；代理须在后续模型调用前核查。不能声称这已成为 Codex 账户硬限额，也不能将缓存输入 Token 当成输出用量或实际费用。

旧预算仍可校验，历史 FaVOR 可显式使用 `register-favor --legacy-replay` 复现并在登记中标记；此入口不授予新增研究资格。已登记旧运行的统计协议保持原义。

## 代码、面板与明细复用

### 历史预算不可恢复时的探索

2026年9月10日，用户确认 A 股完整历史预算已删除并明确授权重新开展探索。此类新计划可显式填写 `historical_budget_status=unrecoverable`、非空 `history_loss_reason`，并将 `historical_attempt_count` 与 `inherited_diagnostic_family_size` 都保留为 `null`。仅允许 `bounded-research-v2` 的 `signal_exploration`，不允许联合确认或组合增量借此绕过历史校正。

当前轮次的候选、机制、比较和资源上限仍必须完整冻结。探索照常执行测量检查、原方向 IC/HAC 和固定成本回测；完整检验族、Bonferroni p 值及统计通过判断为空，不以当前轮次容量冒充完整历史。PostgreSQL 只投影带明确原因的探索索引，Dashboard 不将其标为正式保留。保留已存在的旧候选导出用于查重；丢失记录不能由一份新账本伪造恢复。

共享快照由包内 Python 文件内容确定身份，复制一次后通过运行内的 `code` 或 `code_snapshot` 目录链接复用；不链接可编辑的工作代码。复用前检查完整 Python 文件身份，损坏硬失败，不原地修复。各运行仍保留自身代码身份和研究登记。

默认共享目录为输出目录同级的 `.code_store`。跨不同父目录共享时，显式设置 `FACTOR_MINER_CODE_STORE` 为受控产物存储路径。该位置是复现依赖，不可作为临时缓存随意删除；导出研究包须同时携带共享对象并保持链接可解析。

报价、市值、行业与股份发布的未变化面板通过文件链接引用已冻结上游，不再逐发布复制。衍生行情继续独立写入。引用前后及消费时仍核验发布哈希；上游缺失或内容变化必须失败。这些发布不再保证单目录自包含，不得修改链接指向的输入，也不能随意清理其上游。

月末执行保留订单、选股、净值、损益核对和未确定持仓，将逐日持仓写入 `holdings_daily.parquet`，由 `holdings_manifest.json` 保存行数、格式和哈希；不再同时生成大型持仓 JSON。金融执行合同未变，存储格式以明细清单为准。

相同基线的复用必须同时绑定数据发布、股票池、标签、训练策略、因子身份和成本口径。本次没有引入按名称自动复用预测的缓存，也没有清理已有大文件。

## 代理执行与简短交接

代理负责假设、预算、判断和异常处理，固定计算交给现有 CLI。先完成工程验证，再冻结研究执行；不为每个机制创建同构运行器，不把工程测试数量当作因子证据。

每轮交接只包含研究问题、输入与协议路径、当前阶段、累计资源、关键判断、阻塞原因和已授权的下一步。优先查看汇总及错误摘要，不反复载入全部会话、完整 JSON 明细或整包源代码；只有结果有矛盾时再定向展开。不另生成一套重复报告目录。

```bash
factor-miner preflight-favor <计划文件> <预检报告> --with-data
factor-miner validate-search-budget <计划与累计用量文件>
factor-miner register-favor <计划文件> <新运行目录>
```

回归必须覆盖：预检不读收益、事件容量不足提前收尾且保留名额、资源用量缺失拒绝、达到上限停止、共享快照内容变化隔离及损坏拒绝、面板哈希核验、持仓明细可读取，以及既有 FaVOR 和成交协议兼容。

## 长历史与训练长度诊断

`publish-mapped-history` 从显式字段映射、上游发布身份、冻结哈希与交易日历生成独立历史面板。沿用上游计算、排名、成交及固定开盘标签资格，不重新猜测状态。日期范围只负责裁切；不把当时未上市证券填满历史，也不将当前成分回填。标签仍为固定 T+1/T+6，两端不可成交或缺行时保持空值。已禁用的非交易日行只记录数量并按交易日历排除；存在可用状态则硬失败。

`run-training-window-study` 固定既有因子，使用相同共同截面、预测日期、正则参数、隔离及重训频率，比较 156 周与 520 周训练。历史不足时失败，不能推迟长窗的预测起点再和短窗比较。沿用既有 119 行预热和逐日截面秩模型预处理；原式不重新选方向。输出共同信号、拟合日期审计及逐周 IC，不为同一比较保存多份预测矩阵。

这项比较必须在读取新统计之前登记，继承历史预算；不自动选择最好窗口，不证明长窗必然更好，不作为新增因子数量或交易盈利。更早行情存在不等于已生成的特征和状态具备相同覆盖，应核对实际首个和最后训练样本日期。
