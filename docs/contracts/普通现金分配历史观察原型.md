# 普通现金分配历史观察原型

## 金融含义与时点

原型提供当期普通收入分配比例，供下一阶段数据合同审查，不登记候选或修改评价协议。输入分配额使用前一期末股份单位，与同一期前期价格相除，并对照供应商当期收入收益核验。该比例可以是有效零值；未知分配、无效价格或无法核验的收益关系不是零。

原型只接受固定前一市场交易日的价格期。现金分配按对应收益期结束后的历史观察处理，最早下一市场交易日使用。它不是公告日已知金额、银行到账或可以买入更多股票的现金。历史年度修订与缺少逐次公告金额版本的限制保持不变。

## 输入、输出与失败

正式入口为`factor-miner build-cash-observation-prototype <配置>`。配置显式绑定原始源、字段映射、证券前缀、基础行情主键、状态、市场日历、清单、单位、时点和全部文件哈希；核心不依赖个人目录或数据库。

相同证券日期的源字段全部相同才合并，冲突硬失败。前期日期指向当前或未来、单位核验超出冻结容差、原清单或输入身份改变均失败并保留记录。缺源、无效金额、无效分母、非相邻市场日价格期、缺少同一期供应商核验分别保留未知原因，不前填。

输出独立`cash_observations.parquet`，包含收入比例、有效标记、`positive`／`zero`／`unknown`状态和未知原因。它严格保持原行情证券日期及顺序。原型不会写回原行情、状态、标签，也不会发布新候选或自动接入FaVOR。汇总按原排名状态报告覆盖，不用未来存续证券选择样本。

## 结论边界

稀疏现金观察如何进入连续五分位或条件适用域尚需单独设计；数据原型完成不能宣布构念、预测或组合贡献通过。研究股息总回报还需要权益、除息应收、支付、拆股与终止事件账务；不能把这一比例直接加进原五日价格标签或现金账户。

验证覆盖股份单位重标、合法零值与未知分离、节假日前一市场日连接、非连续价格期、冲突和未来日期拒绝、原始输入不变以及原型不可覆盖。
