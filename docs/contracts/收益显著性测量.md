# 收益显著性测量合同

`rolling_salience_value(x, y, window)` 输入小数制简单日收益与同期市场简单收益。窗口内显著性为 `abs(x-y)/(abs(x)+abs(y)+0.1)`，按显著性降序取秩，并列取平均秩。权重正比于 `0.7**rank`，输出加权收益均值减普通收益均值。

0.1和0.7是固定结构参数，不是数值保护、可搜索参数或预处理。窗口内时间状态排序是测量的组成部分，不做截面排名标准化。算子只接受无量纲输入，调用者必须保证小数制简单收益，不能输入价格、百分数制数字或毛收益。过去收益由固定市场日历计算，缺日不顺延；完整同窗任一非有限值为空，不能缩窗或填补。

Cosemans与Frehen（2021），《Salience theory and stock prices: Empirical evidence》，JFE 140(2)，460–483，DOI `10.1016/j.jfineco.2020.12.012`。[作者所属大学托管全文](https://pure.eur.nl/ws/files/47705178/Repub_134044.pdf)的式3、式8和第2.4节给出权重、显著性函数及参数，第7.4节包括S&P 500背景稳健性。托管文件正文为2021年1月21日待刊排版。平均秩并列规则是本项目事前明确的实现约定，不称为原文已明确规则。

20完整观察、S&P 500价格指数与五日开到开标签是本项目的迁移口径，未复现原文月度组合。原始预期方向为负：较显著的上涨可能引发高估。投资者关注和高估必须另用独立数据验证，合成响应不能把 `mechanism_unverified` 改为机制已证实。

验证使用独立逐项概率求和、并列和置换反例、符号镜像、市场背景变化但股票收益集合不变、多个证券、未来攻击、固定日历缺口和单位检查。浮点近似并列仍可能影响秩，不能以合成测试宣称所有近并列数据稳定；不做事后舍入或分位调整来改善结果。合成股票收益使用不同幅度，避免把价格重标后的浮点近并列误当作有经济意义的顺序。
