# 波动指数上下文

市场波动上升时仍能提供回报的股票，可能具有保险价值。要检验这一主张，需要测量股票对波动变化的响应，不能直接把股票自身低波动或同期市场涨跌叫作波动风险敏感度。

`run-research-report` 可以显式提供 `vix_context_path` 和 `vix_context_contract_path`，仅增加字段 `vix_change`。数据、合同和合同中的公开CSV源路径必须预先纳入 `input_sha256`。上下文含 `date: Date`、`vix_change: Float64`，日期精确覆盖冻结股票日历，不填值，不新增证券行情行。未提供该上下文时不允许公式引用该字段。

`vix-context-v1` 固定定义为 VIX 当日收盘指数点数减去前一个精确股票市场交易日收盘指数点数，单位是波动指数点数，不是指数价格收益或可交易VIX投资收益。合同同时绑定Cboe公开源CSV、研究日历和上下文内容。首日前置市场交易日由上游显式指定，必须早于研究日历；源中没有任何指定端点时硬失败。程序重新读取原始CLOSE并按冻结日历计算全部差分，必须与提供的上下文完全一致。CSV重复日期、结构变化、缺失或非正收盘、派生值不符与字段覆盖冲突均失败。

可得合同为 `after_16_15_et_and_complete_vendor_delivery`，最早交易为 `open_t_plus_1`。它指当晚指数收盘且供应商数据已收齐之后，不能解释成股票16:00整收盘立即可得。具体最终发布时间按指数和日期变化。Cboe历史通知将VIX从2021-09-27起延长至16:16 ET；旧合同中的16:15不是可立即使用的硬截止，仍须等待最终发布及供应商完整交付。提前收市另有安排，最早下一开盘执行。参见[Cboe历史数据FAQ](https://datashop.cboe.com/faqs)。实际CSV历史发布时间未逐日保存时，须标注 `historical_download_no_vintage_guarantee`，不宣称历史版本逐日点时保存。来源页、下载时间、版本及数据审计保留在运行产物。

公式可以用 `rolling_partial_beta` 在带截距的回归中控制同期市场收益，估计股票收益对VIX变化的斜率。原论文曾使用旧VXO，现代VIX并非相同指数；形成窗口、股票池、价格收益及五日标签均须独立冻结。基于现成历史数据的观察不能证明真实保险机制；合成 `volatility_hedge` 反例只检验加入波动冲击响应后测量是否提高。

旧市场收益上下文仍遵守自己的 `market-context-v1`，不能把VIX变化写入 `market_return` 或改变其含义。历史候选重算去重时必须恢复该候选原有的显式上下文身份。

## 波动不确定性与双控制回归

VVIX来自VIX期权，刻画波动本身的不确定性，与VIX水平均有区别。`vvix_context_path` 和 `vvix_context_contract_path` 提供独立 `vvix_change` 字段；`vvix-context-v1` 严格读取Cboe `DATE,VVIX` 两列CSV，按同一股票日历及显式首日前置日计算点差，其余哈希、覆盖、端点和无填补规则相同。可得合同为 `after_required_index_sessions_finalized_and_complete_vendor_delivery`，等待所有所需指数完成当晚最终发布及供应商交付。当前VVIX方法说明正常RTH到16:15 ET，但同时用到VIX时不能忽略它自己的发布安排。

`rolling_partial_beta(x, y, z, w, window)` 支持两个控制变量。典型回归是股票价格收益对VVIX点差，同时控制市场收益和VIX点差。所有四个序列须在同一完整窗口有限；两个控制变量的相关矩阵行列式不超过1e-12，或y去除两个控制变量后残差方差比例不超过1e-12时返回null。保留原三参数数值次序。独立NumPy多元OLS核验斜率、缺失、共线、未来变更和量纲缩放；合成 `volatility_uncertainty_hedge` 只检查测量响应，不证明经济机制。

论文对VVIX暴露的收益方向存在不同发现，候选必须事前说明选定方向、竞争证据、形成窗口及持有期差异，不能把另一方向当作失败后的补救，也不能以本地代理声称精确复制论文。
