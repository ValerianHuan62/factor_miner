# 月末增量模型对照

`run-reserved-factor-models` 执行结果揭晓前已经绑定到 FaVOR 计划的比较清单。它将构念资格与单因子显著性分开：真实测量通过的弱 IC 信号仍可进入原八基线的增量模型；测量失败的分支不执行，名额继续保留。

本入口固定周末训练采样、二十日收益目标，复用冻结的 Ridge 窗口、隔离周数、四周重训频率和正则化强度。历史标签退出必须早于拟合日，未知标签的证券仍保留预测资格。特征先在当日共同可计算、可排名截面交集上构造，再作截面秩除以人数减 0.5；不根据未来收益过滤预测股票池。各模型使用相同截面，结论应解释为该共同截面的增量。

周末配对 RankIC 使用合同固定的 HAC 滞后、历史多重检验族及最少配对期数。月末预测使用不晚于当日的最近一次既定拟合系数，应用当月末的信号，不增加参数搜索或抢先使用未来拟合。月末差额执行与成本比较仍须单独使用冻结比较名额。

输出保存共同特征、拟合系数与退出时点审计、周末预测、月末预测、配对结果以及未执行原因。FaVOR 未通过、无增量、覆盖不足和月度样本不足须分别说明，不能把任意一个步骤通过写成正式可用因子。已消费的历史测试保持已消费。
