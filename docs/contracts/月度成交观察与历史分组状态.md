# 月度成交观察与历史分组状态

## 授权与阶段

本合同对应已确认的有限扩展：使用已有发布，在 `preflight-favor` 中执行月度原始观察和随后历史分组状态的无标签预检。配置版本为 `favor-monthly-state-preflight-v1`，观察 Γ 版本为 `monthly-volume-state-gamma-v1`。Γ、完整假设和输入先冻结，再计算真实观察。预检不生成候选、不预约检验名额、不读取标签，不作为 `register-favor`、`submit-favor` 或 `run-favor` 的替代许可证。

本阶段不扩展原始因子 AST 的排名能力，不把 PATV 当作第二个原始因子。只有观察预检满足必要条件，才有理由另行冻结正式 FaVOR 研究；本合同不改变其五分位、三档严格方向改善、统计、成本或历史预算要求。

## 原始观察

输入必须有同日未复权成交股数、未复权股价和仅拆股复权收盘价；发布合同、源映射协议与文件清单都冻结哈希。可比股数为原始成交股数乘原始股价再除以拆股复权收盘价。该换算用于排除股份单位变化造成的假成交跃迁，不用总收益复权价格。

每个自然月按完整市场日历统计；月末前不能把当前月份当作完整月份。该月所有市场日必须存在有效的计算观察，并至少十日有正成交；否则月均量未知。合法零成交保留为零，不把缺失填零。ATV 为当月日均量与滞后第 18 至第 7 个月的十二个完整月均量之比的自然对数。历史基准采用各月等权，不以十二行代替十二个连续月份。

日历末端可能被截断；只有日历已包含下一个自然月，才能确认上个月完整。预检核对发布实际截止日以及日历、状态版本的文件哈希。截止日检查只读取日期列，不读取未来行情字段或标签。

月末股票池取原发布 `valid_for_factor_rank` 且原始股价至少一美元的证券。未知原始股价不能猜测资格。计算覆盖不足的证券仍保留在事前股票池分母中。原始观察不做截面排名、缩尾或中性化。

## 后续分组状态

仅在有效月末观察中，以平均秩减半再除以截面数量定义百分位。百分位至少 0.9 为高组，至多 0.1 为低组，其余为非极端组；并列值保持同组，不按证券编号拆分。

PATV 记录连续处于同一极端组的月份，正负区分高低组，五个月以上合并为正负五。已知非极端状态为零，缺观察为未知。首次看到一个极端状态时，不能推断它刚开始；缺月、缺行情和失去排名资格同样使起点未知。只有观察到此前月份的不同已知状态，或已连续观察满五个月，持续状态才重新可识别。

月度原始表和分组状态表分别保存，各有哈希。状态只在完整月结束后可用，后续使用不得提前回填到月内。

## 可行性与停止

本次固定检查“高 ATV 且 PATV 为一”的早期异常成交主张。只数每月一次的事件，报告三档数量、整个事前股票池中同时达到每档至少五次事件的证券比例，保持至少二十只证券、50% 事件支持和 80% 覆盖要求。相同事件集合不满足现有方向选择性中的严格改善条件。

该主张中的 PATV 为一已蕴含最高十分组，因此再叠加 ATV 的 q50/q70/q90 会产生相同集合。这是测量与既有筛选协议之间的结构冲突，不是收益证据。预检应明确失败并保存观察，不应改持续月份、分位阈值或支持率分母来救结果。方向统计、收益和交易均不执行。

CLI 的 `passed` 表示合成测量检查通过；真实可行性另看 `data_feasibility.feasible` 与 `needs_review`。观察计划不会被正式候选登记器接受，防止把工程结果升级为因子通过。

```bash
factor-miner preflight-favor 月度观察计划.json 月度观察预检.json --with-data
```

输出旁的 `.monthly_state` 目录保存冻结计划、Γ、代码身份、月度原始表、状态表及失败记录。已有文件不可覆盖。失败重试必须使用新输出身份，保留旧记录。正式主存储仍为文件，PostgreSQL 和 Dashboard 不因此增加候选。

## 文献和复现边界

依据 [Li、Yin、Zhao（2024）](https://doi.org/10.1080/1351847X.2024.2303092) 第 2.1、2.2 节的核心测量。完整 PDF 尚未取得；成交复权、完整交易月、并列值及未知起点采用以上显式保守合同，不声称完整复现原文的所有数据处理。历史发布经过年度修订，没有逐日数据版本保证。合成检验和真实状态表都不能独立证明投资者情绪或 pure alpha，保持 `mechanism_unverified`。
