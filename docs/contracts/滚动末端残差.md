# 滚动末端残差

`rolling_residual_last(y,x,window)` 在同一证券的完整有限窗口内，用带截距的一元OLS回归y对x，输出当前最后观察的有符号残差。x恒定或不足完整窗口时为空；真实常量y可产生零残差。量纲继承y。这个量使用信号日已知数据，是同期残差测量，不是对信号日的样本外预测。

原始层的时间序列回归只用于去除共同市场变化，不做截面排名、中性化或缺失填零。同一窗口所有残差的均值为零，不能用它作为近期压力；可以对每日分别滚动拟合得到的末端残差作另一个完整时间窗口平均。二者不同，测试必须明确区分。

用60观察日回归末残差再作20观察均值，配合精确上一市场日的价格收益时，回看79市场/观察偏移上界；证券缺少上一市场日就产生缺失，不向前寻找最近报价。市场字段来自显式冻结发布。

独立NumPy带截距OLS验证末残差；增加任意常数或既有市场线性成分不改变残差，放大y会同比放大残差。验证分组隔离、非有限控制、未来扰动、双层滚动均值，以及合成逐渐增大的市场外压力响应。

研究动机参考[Blitz等的期刊摘要](https://www.sciencedirect.com/science/article/pii/S1386418112000468)。原研究剔除Fama-French因子并以残差波动缩放；仅剔除S&P500市场、不缩放、日频窗口和五日标签均为明确不同的新假设，不能声称复现原文收益或已控制规模和价值暴露。数学测量通过不验证过度反应机制。
