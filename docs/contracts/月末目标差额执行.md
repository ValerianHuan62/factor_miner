# 月末目标差额执行

月频策略在每个月末用当时信号更新目标持仓，下一市场交易日开盘只买卖实际持仓与目标之间的差额。股票仍在目标组合中时，不为满足固定二十日持有期而先清仓再买回。预测未来二十日收益与实际持有到下次月末决策是两种独立口径，必须分别冻结。

## 日程与资金不变量

- 使用完整市场日历取各月最后一个交易日。请求区间在月中结束时，不把该日提前当月末。信号后下一市场日才可成交。
- 前一期窗口结束于下一期入场日；最后一期使用事前显式指定的 `liquidation_date`，不是自动延长二十日。该日必须晚于最后入场，且落在市场日历内。
- 先按信号日信息冻结证券和权重。交易日开盘价只用于数量与成交计算，不用未来可成交状态重选证券。
- 保留目标内的现有份额，只卖超额、买不足；实际买卖收取完整双边成本参数的一半。目标股数不变时不产生整篮子往返费用。
- 卖不出则锁仓并按市场日逐日重试；资金到账前不能支持替代买入。未成交买单持现金，不在其他日期补买。
- `observation_end` 是显式结算观察终点，可晚于计划清仓日。仍无法确定终值时，实际最终净值为空，最后报价参考估值和零回收压力另列。

## 正式入口与输入

使用 `factor-miner run-monthly-target-execution CONFIG_PATH`。一个配置只执行一个已经预约的模型、成本和日程情景，不训练模型、不搜索窗口、不自动组合或比较多个成本情景。

| 配置字段 | 要求 |
| --- | --- |
| `version` | `monthly-target-execution-v1` |
| `run_kind` | `research` 或 `synthetic_demo` |
| `code_commit` | 真实研究记录完整提交哈希，实际运行内容另外绑定代码快照；合成演示使用明确的合成身份 |
| `dataset_root` | 显式标准面板目录，含 `market.parquet`、`state.parquet`、`calendar.parquet`、`manifest.json` |
| `release_path`、`market_id` | 有完整来源、版本、复权、交易日历和状态身份的 `FavorDataRelease`；市场与终点须吻合 |
| `scores_path` | 冻结分数，包含 `signal_date`、`security_id`、`factor_value`；不允许重复证券日或缺少计划月末 |
| `prediction_horizon_sessions`、`test_consumed` | 明确预测期限 1／5／20 日及历史消费状态；这里只记录，不据此认证上游训练没有泄漏 |
| `signal_start`、`signal_end` | 信号采样范围，按完整日历识别月末 |
| `liquidation_date`、`observation_end` | 最终计划清仓日与结算观察终点 |
| `direction`、`group_count`、`round_trip_cost_bps` | 显式方向、分组数及完整买卖双边成本 |
| `terminal_policy`、`terminal_events_path` | `fail_closed` 或 `report_unresolved`；没有独立终止记录时路径显式为 `null` |
| `reservation_path`、`comparison_id` | 已冻结有限比较预约；包含正整数 `capacity` 和不超过容量、无重复的 `comparison_ids`，本次编号必须在其中 |
| `input_sha256`、`output_root` | 全部依赖内容哈希与全新独立输出目录 |

行情和状态必须覆盖完整的执行市场日期，不能压缩缺日。可计算、可排名、可开仓和可平仓状态须显式提供；预测、数据发布、面板清单、终止事件与比较预约均绑定哈希，计算前后核对。代码保存独立快照，并核对运行期间未变化。

比较预约用于绑定本次执行与有限研究清单，本身不构成新增研究授权，也不是跨目录的全局预算分配器。研究协调者仍须在主计划中预登记全部比较，保存失败和重试记录；不能换目录复用同一名额来扩大实际比较数。

## 输出与结论边界

输出包含配置登记、代码身份、月末日程、冻结选择、订单、逐日持仓、损益对账及回测情景。`summary.json` 的 `actual_final_nav` 只在已完成结算时有值；未确定持仓对应 `return_series_kind=reference_valuation`。每次执行都对账持仓损益、费用和现金与净值变化。

本入口不读取预测标签，不验证原预测训练过程，不计算新增因子资格，也不把旧历史重新认证为密封样本外。它与 FaVOR 联合筛选及组合增量统计分别记录；[FaVOR 多期限入口](FaVOR多期限执行协议.md)的固定持有结果不能冒充本口径。

底层增加频率无关的 `target_difference` 执行名称，旧 `weekly_target` 的算法与结果身份保持原样。月末合成回归覆盖节假日导致的十九日月份、持仓不变、价格漂移、锁仓、未来无法买入、未确定终值、正式 CLI 和输入哈希变化；工程通过不代表真实月频策略已经通过。
