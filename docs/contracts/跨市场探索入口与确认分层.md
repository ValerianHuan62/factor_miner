# 跨市场探索入口与确认分层

## 审查结论

2026年9月10日按用户要求修订 A 股与美股共用入口。近期零保留混合了测量错误、身份重复、样本不足和联合条件不适配，不能汇总为收益失败。已核对的例子：RET20 构念通过但另一条件重复；行业相对反转在事件预检停止；早期 PATV 已限定最高十分组，叠加三档百分位会产生相同事件集合。

旧五分位实现还要求尾宽变化及均值、中位数逐组一致单调。这些检查可能适合特定主张，但不能自动成为所有测量的必要条件。旧实现和冻结结果继续保留；本次不靠修改旧门槛重新标记失败。

合成检验原先取响应差的中位数，少于半数日期变化的稀疏事件可能被判为零响应。新协议对状态与事件采用方向变化计数：至少两个有限观察按预期变化，且没有超过数值容差的反向变化；量纲与其他合成检查仍必须通过。连续测量和旧版本继续使用原中位数规则。这是合成测量功能检查，不是统计显著性检验。

新增 `favor-exploration-v1`：论文方法核验 → 可证伪经济假设 → 数据与算子可行性 → 冻结类型化测量、状态、预算 → 公式提交 → 测量探索资格 → 固定方案诊断。A 股 DeepSeek 与美股 GPT‑6 共用 CLI、类型合同、编译和统计代码。

## 三层结论

1. 正确性：数据发布、时点、mask、固定日历标签、Γ、白名单 AST、合成响应、缺失语义继续硬失败。
2. 探索资格：按事前信号类型验证测量与样本支持。资格在读取收益前冻结，不要求边际 IC 为正或显著，不要求另一个条件同时通过，不要求五组或 q50/q70/q90 逐股改善。
3. 最终确认：探索入口不授予此资格。独立确认、成本、稳定性、冗余、多重检验和组合增量仍须另行冻结并执行。原 `favor-regime-v1` 联合确认协议保持原样；探索结果不会自动被它接受。

本次没有实现一个替代全部最终确认要求的新筛选器，也没有新增自动晋级或组合优化。尤其对无法表达三档联合主张的事件信号，不得为通过旧联合协议而改写经济假设；须先登记与该目标匹配的独立确认研究。

## 类型化测量

`exploration` 逐条件保存 `ExplorationMeasure`，绑定整个计划哈希，并随 `favor-request` 提供给两个公式生成入口。

| 类型 | 测量检查 | 固定方案的激活方式 |
| --- | --- | --- |
| `continuous` | 按日期计算原始信号与每个事前状态锚的截面 Spearman；有效日期的中位数符合预期方向，默认绝对关联至少0.3。常数信号失败。 | 沿原激活方向取唯一事前百分位，默认0.9。 |
| `state` | 原始值必须属于声明的有限状态；激活组与非激活对照组的同日均值差，中位数符合各状态锚的事前方向。 | `active_values` 精确匹配，所有非激活已知值作为对照；不强迫二元状态形成五组。 |
| `event` | 同上，但只统计已知非激活转为激活的开始日。有效事件证券数、共同对照日期及事件样本须达到事前支持要求。 | 只在开始日触发；连续激活不重复计事件，缺失后不能猜测新事件。 |

离散测量的 `expected_direction` 指激活组相对对照组的测量方向，不能把任意类别编号当作有序强度。无法形成可解释的两组比较时，应提出适合的测量合同，不将标签改成连续类型绕过检查。

`min_dates`、`min_assets`、`min_group_samples` 必须显式填写，并有至少十字的 `rationale` 解释抽样与支持依据。它们只代表可探索的观测支持，绝不宣称小样本统计显著。覆盖率下限仍为80%，但分母是当时可排名范围，分子是测量已知的数量，**不是事件触发比例**。非触发是已知对照；缺失仍为未知。所有事前状态锚都检查，不能看结果挑一列。

`observation_frequency` 冻结为日、周末或月末。完整市场日历决定观察日，末尾未完成周/月不认证；日历元数据可以用于识别周期边界，不能读取未来行情决定信号。月度测量不会复制成每天一个构念或 IC 样本。

单只股票不必反复发生稀疏事件，也不必有半数全市场股票满足三档重复次数。事件开始仍按市场观察日连续性判断，避免停牌或缺失造成虚假开始。测量资格不足记 `insufficient_sample`；方向不符记 `measurement_mismatch`，均不等于收益失败。

## 探索诊断与统计边界

检验结果表同时显示 `ic_mean`（逐日截面 Pearson IC 均值）与 RankIC（逐日截面 Spearman IC 均值），直接读取冻结结果，不以一列替代另一列。未评价或不适用的结果保持空值；探索和联合确认页面使用相同字段含义。

`exploration_freeze.json` 在收益打开前保存合格信号名单。每个合格信号独立完成固定方案的诊断；未提交、编译失败、重复或测量失败的其他槽不阻断它，也不从账本消失。

- 发现期：复用原始方向的 IC、RankIC、HAC 与完整 Bonferroni 预算，不以高低决定探索资格。沿用60个有效截面日期、每日20只证券的 IC 统计要求；不足只记诊断样本不足。事件开始的主要观察不是全截面排序，首版不计算其单因子 IC 通过状态，记 `not_applicable`。
- 验证期：每个信号只有一套事前激活方案，沿冻结频率、持有期和成本情景运行因果多头引擎；与同范围等权基准比较，不搜索最好阈值。该组合展示的是激活证券的收益，不将负预期方向偷偷翻成做空或反向因子。
- 执行：信号时决定证券，下一市场交易日成交；不能买入留现金，退出受阻锁仓，未确定终值保留实际/参考/零回收区分。验证持仓退出须早于测试起点。
- 测试期：本入口不计算测试期 IC 或策略表现，`test_evaluated=false`、`sealed_oos=false`。输入整体文件哈希校验不等于测试收益评价。历史 `test_consumed` 标志原样保存，旧数据重新探索不会恢复为密封样本。

`exploration_evaluated` 只表示诊断完成。无论收益正负，`retained_components=0`、`retained_combinations=0`。没有 IC 检验结果时统计通过标志为空，不能将“不适用”显示成统计失败。Dashboard 单列“可继续探索”；PostgreSQL 仅允许试验索引，不允许将探索结果投影为正式保留组成。

## 预算、去重与兼容

真实研究仍使用 `bounded-research-v2`，但目标明确为 `signal_exploration`。候选、信息来源、机制、模型比较、时间、产物及模型使用计量都保留。最小模型预算按每槽一次 IC、一次测量方向比较、一次基础成本诊断、各压力成本诊断，加一次共同基准保守预留。旧失败、重复、中断及未执行预约不缩减历史校正。

新入口允许一个条件和一个公式槽。为复用数据与执行合同，保留 `integration` 中唯一阈值向量，须与逐条件 `activation_quantile` 一致；它不触发联合三档筛选，离散信号实际使用 `active_values`。

历史规范 AST 仍查重；本次没有开放“旧公式换名再登记”，也没有自动恢复任何历史候选。构念相关代理相同只证明测量符合，不构成独立经济机制证据。

旧版本结构和序列化不增加新字段；旧 `run-favor` 的五分位、方向选择性、成本、统计和出版边界不改变。新版本通过同一 `parse_favor_plan` 路由，不允许旧配置隐式升级。

## 正式入口

```bash
# 默认导出两市场共用的探索计划结构。
factor-miner favor-schema /tmp/探索计划结构.json
# 原联合确认结构仍可显式导出。
factor-miner favor-schema /tmp/联合确认结构.json --protocol regime

# 先起草并核验论文、经济假设、状态与探索合同，填写实际发布及预算。
factor-miner preflight-favor /绝对路径/计划.json /绝对路径/预检.json --with-data
factor-miner validate-search-budget /绝对路径/预算与提案.json
factor-miner register-favor /绝对路径/计划.json /绝对路径/新运行目录
factor-miner favor-request /绝对路径/新运行目录 F1 /tmp/公式请求.json --producer gpt6
# A 股可使用 --producer deepseek_api；真实模型调用仍须已有授权及录制。
factor-miner submit-favor /绝对路径/新运行目录 /绝对路径/公式提交.json
factor-miner run-favor /绝对路径/新运行目录
```

这次修订不启动真实研究，不恢复自动续跑，不重算旧候选。后续使用哪个市场、哪些数据和经济问题，以用户下一次研究授权为准。
