# 周频目标差额交易与十五因子目标

## 研究目标与资格

保留每周决策和五交易日预测标签，在原八因子基础上研究可用于简单策略的十五个候选。原八因子的公式、方向和历史结论保留；研究输入资格不能自动升级为新 FaVOR 协议通过。

本轮冻结十二项联合主张、四十八个候选槽和二千零四十八个模型与执行比较名额。四类研究动机是流动性压力、隔夜与日内分化、价格锚、信息扩散；它们共享量价信息来源，不宣称十二种独立信息。窗口变体、失败、重复和编译失败均占名额。继承一百零五次历史尝试和 13061 倍诊断预算，统一诊断分母为 15157，不随目录或批次递增。精确假设、Γ、槽位和输入身份在本轮私有不可变计划中登记。

发现期为 2021—2023 年，2024 年选择冻结验证阈值，2025 年截至十二月十二日信号作已消费历史复核；行情观察至十二月三十一日。不得等待、回填或挑选具有 2026 年行情的证券。历史复核不是密封样本外。

十五个的计数要求同时完成以下检验：

- 构念与覆盖、FaVOR 三档选择性和联合策略验证沿用既有冻结合同；单独 IC 弱不提前删除组合输入。
- 相对原八及新增有效代表，发现期逐日截面绝对 Spearman 的 95 分位小于 0.75；至少六十日且每天二十证券。相同输出和替补不重复计数。
- 固定 Ridge 增量或逐项消融的配对 RankIC 差在 2024、2025 年均为正，合并 HAC 校正 p 不高于 0.05；报告系数方向冲突。与原假设冲突的反向系数不能证明机制。
- 周频目标差额组合在 20bps 完整双边成本下两年净收益均为正，两年均不劣于原八组合，40bps 全期净收益非负。未确定终值时实际指标为空，不能判为通过。

达到十五个且完成整体组合检验才达成目标；预算耗尽仍不足则保留缺口，不放宽标准。即使通过，也只能称“通过当前已消费历史协议验证的候选因子”，不宣称纯 Alpha 或实盘可用。

## 每周目标与实际成交

这是独立的 `causal_weekly_target_v1` 执行版本。默认 `fixed_horizon` 保留原批次五日退出语义。新模式不改变五日标签和信号日选择，每个冻结入场日更新目标；个股可连续持有至后续周，不强制卖出后当天买回。

信号日在可排名截面冻结前十分组证券和等权目标；下一市场交易日开盘按目标差额交易。先处理已可得的终止结算，再按可卖状态标价，计算交易前净值和目标股数。已有持仓优先保留目标所需股数，仅对超额部分和退出名单发出卖单；新增与不足部分发出买单。

卖不掉的超额部分锁仓并逐市场日重试；下一周目标可重新决定其保留或退出。买单仅在冻结入场日尝试，失败留现金，不候补、不跨日补买。可用现金不足时对所有合法买单按同一比例缩减，包含费用，不复用锁仓资金。缺开盘价时无法计算新的股数目标：已有同证券数量保持，新增买单拒绝并记录，不用未来价格补算。

完整双边 20bps 对每笔实际买卖各收 10bps。未发生的抵消买卖不计费用，不能从旧回测事后直接扣除一项“节省”。保留每笔订单、持仓及现金损益，与每日净值对账。

节假日仍使用预先冻结的每周信号和下一交易日入场；旧持仓目标持续至下一周实际更新日。末个窗口固定 T+6 日清仓，卖不掉逐日重试至观察终点。未知终值分开报告最后报价参考值和末日零回收情景，实际收益保持空值。

## 验证与正式入口

合成回归验证目标不变无重复交易、价格变动下只交易差额、锁仓不能融资新买入、部分减仓失败的损益加总、未来状态不改变选择和节假日每周更新。

```bash
factor-miner run-weekly-target-study <冻结配置>
```

配置先绑定分数、行情、状态、日历、终止结算、参考回测和合同哈希，登记后计算。同一分数比较原固定窗口与每周差额方式，固定 0/10/20/40bps；保留逐年表现和现金。仅提高换手效率不能替代新增预测信息验证。
