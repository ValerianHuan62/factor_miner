# 共同下跌半贝塔数据合同

`rolling_negative_semibeta(y,x,window)` 计算完整同窗的 `sum(min(y,0)*min(x,0))/sum(x*x)`。分母是全部市场收益平方和，非下跌日平方和、非中心化方差；分子不减均值，也不是仅在下跌日拟合的OLS。返回单位为y/x。

窗口不足或任一非有限值返回空；分母为0返回空，不加epsilon。完整窗口中确实没有共同负收益时返回0，这是观察到的无共同负乘积，不是缺失回填。零收益不贡献分子。结果非有限时为空。

股票收益用精确上一市场日的价格差除以前价，市场同期价格收益。先做原始时间序列测量，再沿用统一预处理。正数改变收益计量单位有相应比例变换，平移收益会改变零分界，因此不要求平移不变。独立标量求和、缺失日历、未来攻击和共同下跌幅度响应核验该定义。

此量对应Bollerslev、Patton、Quaedvlieg研究中的共同负收益组成项，但本项目20观察、五日标签及市场和股票池合同与原论文不同，不能把论文收益或高频一致性结论移植为本候选的通过结论。
