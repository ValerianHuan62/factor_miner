# 跨市场假设约束与 FaVOR 联合研究

2026年9月10日补充：新增 A 股与美股信号探索采用[跨市场探索入口与确认分层](跨市场探索入口与确认分层.md)的版本化入口和 `signal_exploration` 预算目标；本文件原有联合确认或历史研究池规则继续约束其原版本，不自动套用为探索准入，也不改写旧结果。

## 研究目的与边界

`favor-gamma-v1` 将研究对象从孤立公式扩展到一个高层假设及至少两个可观察条件。A 股的 DeepSeek API 与美股的 GPT‑6 只是候选生成入口，使用相同合同、编译器、构念验证、联合触发、阈值选择和投影规则。新研究使用此入口；旧批次可以复现，但不能自动升级为新协议通过。

测量正确、单因子预测显著、联合条件有用和成本后策略表现分别记录。所有结果仍为通过当前协议验证的候选，保留 `mechanism_unverified`。旧区间已被观察时必须填写 `test_consumed=true`；走步或时间分区不能消除既有选择偏差。

本合同是用户要求的 FaVOR 联合策略路径；既有 Ridge 作为独立对照保留，不再充当新联合研究的唯一组合方式。历史单因子统计结论、试验族与归档痕迹不改写。

## 两篇论文的采用范围

- [AlphaLogics 附录 A.4](https://arxiv.org/html/2603.20247#A4)：借鉴事前结构化假设到可执行约束的确定性编译。自然语言到结构化合同仍由研究者或生成模型提出、在结果之前审定，不声称通用自然语言语义证明。
- [FaVOR 第三节及附录 B](https://arxiv.org/html/2608.30192v1#S3)：借鉴假设分解、训练期五分位市场状态验证、多条件联合触发、q50/q70/q90 三档方向选择性、验证期阈值优化和冻结后的测试。

这是适配本项目数据和执行规则的实现，不宣称论文收益复现。保留本项目 T+1/T+6、事件 purge、非成交现金、退出锁仓、终止价值与有限预算。FaVOR 原文的语义变量映射在这里变成事前明确的 `StateMeasurement`；最终程序判定不能被 LLM judge 覆盖。

## 事前合同与 Γ

`FavorPlan` 保存完整高层假设、每个条件的 `ConditionContract`、各候选槽、数据发布、发现/验证/测试区间、预算和执行规则。登记先于公式提交。

每个条件包含：观察状态、测量依据、合成响应测试、状态激活方向、单因子预期收益方向、真实状态测量表达式，以及 `ExpressionConstraint`。激活高值或低值与预期收益正负分别记录，不用其一推断另一项。

结构约束固定树的运算关系，在每个节点声明有限的算子、字段、窗口、滞后和常数集合。程序要求必需变量实际出现，并逐节点匹配；全局 DSL 继续检查未来信息、运算参数和复杂度。20日合同不能用40日公式通过；整体取负、删除条件变量、交换分母等必须被原结构拒绝。允许多种表达形式时事前显式列入有限选择，不能看到结果后放宽约束。

`compile_gamma` 为纯函数，绑定原假设内容及条件，不读取结果。公式提交携带计划和 Γ 的身份。`compile_candidate` 对带 Γ 的候选强制执行同一校验。旧 A 股逻辑适配器补传观察合同与测量合同；携带新合同的标准工作流也执行真实构念检查，不凭旧 semantic lint 放行。

## 数据与分区

输入路径必须显式指定并绑定文件哈希，包含 `market.parquet`、`state.parquet`、`calendar.parquet`、`label.parquet` 和发布合同。发布合同使用 `FavorDataRelease`，填写市场、来源、发布版、复权口径、日历、状态表和一致截止日。额外市场上下文字段须已在发布中按可得日对齐，不能临时连接未知版本。

行情主键为 `date/asset`，包含声明的原始字段及 `open`。状态表提供非空布尔的 `valid_for_factor_compute`、`valid_for_factor_rank`、`can_open_long`、`can_close_long`。标签字段为 `label_o2o_5d`、`label_entry_date`、`label_exit_date`；有限标签必须严格对应统一日历 T+1/T+6。缺日不顺延，缺标签的信号不删除。

发现期构念只读当期市场状态，不读收益。发现期 IC 与方向选择性清除退出日不早于验证起点的标签。验证回测只保留退出日在测试起点之前的窗口，不能借测试期持仓结算挑选阈值。

## 五分位构念检验

每天按因子平均排名分成五组，相同因子值不按证券编号强行拆组；常数因子不能伪造五组。每个事前指定状态变量计算样本数、均值、中位数、q10、q90、标准差。只统计发现区间，但滚动状态在完整历史上计算。

默认信号覆盖中位数至少80%，每个有效截面至少20只证券、至少60日、每组至少20个有效样本。四项程序检查为：组序与均值存在足够关联；尾宽存在超过尺度容差的变化；均值和中位数的相邻变化一致；变化方向符合事前语义映射。默认相对容差为 `1e-6`，组序相关绝对值至少0.5。全部事前指定观察量必须通过，不能看结果后挑最支持叙事的一列。

真实状态代理须匹配机制，不局限于四个通用 OHLCV 指标；可使用合同允许的市场下行等上下文。若代理与因子完全同义，结果只能证明测量实现符合，不构成独立经济机制验证。合成测试与真实检验均须通过。

## 多条件联合触发与阈值检验

每个条件从其构念通过的候选中选择一个，形成事前预算覆盖的笛卡尔积。相对于本轮当前有效代表检查发现期每日截面绝对 Spearman 的95分位，默认达到0.75视为冗余，至少60日且每日20只证券。历史失败公式只作为身份查重对象。任何条件没有有效代表，整个联合假设不成立，不能偷偷减少条件数。

按各自激活方向计算当日截面百分位。一个组合只有每个条件都越过各自阈值才触发，使用 AND，不取平均排名替代。无触发日持现金。排名不读取未来标签或未来成交状态。

方向选择性固定三档共同阈值 q50/q70/q90。发现期逐证券比较平均固定持有期标签收益和胜率；默认每档至少5个事件，至少20个证券。平均收益或胜率随阈值收紧不下降且端点改善，并要求最严格档平均收益为正，才计为支持。默认支持比例至少0.5。最低档触发而高档样本不足的证券仍留在分母，避免只报告有利证券。

逐条件最终阈值向量在计划中预列。只对通过方向选择性的组合，在验证期用同一个因果成交引擎计算成本后 Calmar，选择有效候选中最大者；不是用未来标签均值冒充策略净值。无交易、终值未知或回撤为零不能用无限/伪造 Calmar 参与选择。所有候选阈值及失败原因均保留。

最终组合、组成因子和阈值写入 `strategy_freeze.json` 后，再计算测试结果。测试期不换方向、不换阈值、不按测试收益重新选组成。联合策略选择触发证券等权；单因子对照仍为定向前10%等权。复用固定五交易日持有和原订单状态机，默认双边10bps，并输出20/40bps情景。实际、最后报价参考与零回收压力分列。信息比率以同股票池等权基准计算；单因子胜率沿用定向两端净收益之差的逐日 `Q10_Q1_net_return`。

## 统计预算、入库与历史

有限机制预算沿用 `validate-search-budget`。候选槽在生成前预留，失败、中断、重复和未提交均不缩减多重检验族。模型预算覆盖笛卡尔积、三档训练筛选、验证阈值、测试成本情景、单因子两端对照及基准，超过预算拒绝登记。

构念通过的候选允许进入联合检验，不能要求每个必要条件都单独预测收益显著。发现期单因子原方向 HAC/Bonferroni 通过状态单列，联合组成资格不改写该结论。

JSON/JSONL 为主存储。PostgreSQL 的 `favor_factors` 仅保存最终联合策略的保留组成，`favor_combinations` 仅保存保留组合；其他候选只写 `favor_trial_records` 的编号、状态、原因、原产物位置和身份。复用既有事务内全库 `huanNNN` 编号表，A 股和美股按市场隔离，重复发布不重新编号。已有 `screened_factors` 等历史表保持原语义。合成演示禁止写入研究数据库。

## CLI 与 Dashboard

```bash
# 导出计划 Schema；起草、核对后才冻结。
factor-miner favor-schema /tmp/favor-plan-schema.json
factor-miner register-favor /绝对路径/计划.json /绝对产物根/favor/研究名

# GPT‑6 根据合同生成提交；DeepSeek 使用同一合同的已录制请求。
factor-miner favor-request /绝对产物根/favor/研究名 F1 /tmp/gpt-request.json --producer gpt6
factor-miner favor-request /绝对产物根/favor/研究名 F2 /tmp/deepseek-request.json --producer deepseek_api
# DeepSeek 继续使用既有 llm-execute 的政策、授权和调用录制。
factor-miner import-favor-response /绝对产物根/favor/研究名 /绝对路径/已录制调用目录
factor-miner submit-favor /绝对产物根/favor/研究名 /绝对路径/GPT提交.json

# 封存后不再接受候选。只运行一次，失败记录不覆盖。
factor-miner run-favor /绝对产物根/favor/研究名
factor-miner publish-favor /绝对产物根/favor/研究名 --dsn-env FACTOR_MINER_TARGET_DSN

# 完全合成的闭环演示，不调用模型，也不入库。
factor-miner favor-demo /tmp/favor-demo-us --market-id us_equity
factor-miner favor-demo /tmp/favor-demo-a --market-id a_share
```

演示生成的计划完整展示字段结构，`run_kind=synthetic_demo`，少量支持门槛专用于工程测试，不能原样当作真实研究政策。

Dashboard “挖因子”默认进入两市场共用 FaVOR 页面；“看结果”可选择 FaVOR 联合策略。读取当前市场配置的 `artifact_root/favor/*`，展示自然语言条件、提交/构念通过/保留因子/保留组合四个数量、三档阈值统计、冻结阈值、成本情景和净值。默认不展示 JSON、哈希或代码。已有研究流程保留为明确的历史入口。
