# 历史行业同业收益发布

行业信息传播需要区分共同市场变动、同业领先与个股自身收益。本发布使用历史有效区间中的SIC两位分类和发行人身份；不使用最新行业回填过去。历史分类有效日不代表已经核验原始公告可得日，沿用年度历史发布的修订限制，研究结果仍有该边界。

`factor-miner publish-industry-release <配置>`只读基础发布和显式行业主表。输出独立发布，原行情字段、可计算／可排名／可交易状态、固定标签和终止价值保持不变。行业及发行人区间冲突硬失败，未知分类或发行人不猜测。发布前后核对输入、代码、日期、日历与状态身份，保留全部哈希及代码快照。

使用前一个固定市场交易日的证券美元市值作为权重，缺少该日市值不退回更早一行。按当日可排名资格、历史有效行业及发行人分组，多股类市值合并为发行人规模。在每个行业中按发行人前日规模的平均排名选择最高30%作为大公司；相同规模不按编号拆组。选择过程不读取当前或未来收益。

`industry_peer_return`为行业内排除整个自身发行人后的前日市值加权已实现价格收益；`industry_leader_return`只使用上述大公司，并同样排除整个自身发行人。收益来自基础发布已按固定前一市场日校验的 `stock_price_return`，不是新的评价标签。计算日期为收盘后，最早下单为下一交易日。

全体同业至少需要20个其他发行人，大公司收益至少需要3个其他大公司发行人；这两项门槛分别适用。已知收益对应权重至少占预选同业权重95%，以已知权重计算平均收益；缺收益不会改变原先的规模排名。未达到人数、正权重或已知权重覆盖的结果为空，不作为经济零。权重之和减去本发行人权重，收益加权和也减去整个本发行人贡献，避免多股类自我解释。

这些是明确计算定义的同业收益观察变量，原始因子仍通过类型化AST生成。行情字段新增 `industry_leader_return`、`industry_peer_return`，并保留行业、发行人及人数供审计。构念检验独立扰动同业领先收益均值和个股对滞后同业收益的条件beta，分别检验测量响应；这些合成检验不证明经济机制。

回归覆盖同发行人多股类排除、前日权重、缺日不顺延、未来分类不回填、区间冲突、未知身份、原面板不变以及两种构念方向的反例。缺失数据或覆盖不足不能通过降低既有FaVOR门槛补救。
