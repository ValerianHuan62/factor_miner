# A 股双边万14成本与研究候选入库

2026年9月10日用户明确指定买卖合计万14，并批准通过基础筛选后加入研究候选库，保留待正式确认标签。

新增计划已经事前采用万14时，通过 `export-favor-research-candidates` 复用原始交易诊断并导出研究候选，随后使用 `publish-favor-cost-review` 发布。导出绑定计划、完成回执、候选公式、汇总与交易明细哈希，指标必须与原冻结汇总一致；不重复回测。未确定持仓、最后报价参考估值与零回收情景仍引用原完整诊断。Dashboard累计清单绑定每批汇总与发布回执，显示原有与新增候选，拒绝重复编号及身份变化。

## 成本与筛选

A 股后续新挖掘采用 `round_trip_cost_bps=14`，即总费用0.14%，引擎按买入和卖出各7bps扣除。这是包含费用与滑点预算的统一研究假设，不是已校准的资金容量模型。20、40bps可以保留为压力诊断，不作为本次研究候选入库硬门槛；美股和既有冻结计划不改。

本次复核覆盖此前15个已评价A股探索信号，DAY20未计算，不补造结果。公式、原方向、持有期、激活阈值、股票池、日期与成交规则全部复用。每个候选先复现原20bps指标，再以14bps重跑因果现金与交易引擎，不能直接在年化收益上加回费用。

研究候选资格要求：基础构造和测量检查通过，发现期IC与RankIC均符合原方向，验证期14bps参考年化大于零。该规则是在旧结果已被看到后制定的研究筛选，不能声称事前独立验证。已知高度相关者保留同类关系，不认定为独立增量，不根据成本结果翻方向。

## 入库与边界

本次为用户批准的研究候选入库版本，允许历史统计通过状态未知的信号带标签入库；不修改原统计结果，不投影成 `retained_component` 或正式投资表现通过。完整历史预算未知、独立机制未验证、测试期未评价等状态永久保留。

未确定终值时实际年化收益、回撤、Sharpe保持空值，参考估值与零回收压力分列。研究库使用稳定顺延的huan编号，与原huan001共享编号分配锁和身份映射；候选不重新编号。PostgreSQL及Dashboard是独立复核文件的可重建投影。

## 执行与核验

正式入口为 `factor-miner run-favor-cost-review CONFIG`。配置提前绑定原计划、完成回执、摘要、原始因子矩阵及其哈希，使用新目录，保存代码快照、追加事件、交易明细和完成摘要。原研究结果保持原样，失败运行保留。成本复核不增加公式变体，也不减少旧多重检验名额。

回归覆盖正收益不能修复反向假设、缺少构造检验不能入库、非正或未知收益拒绝、研究资格不自动变成正式通过。真实执行逐候选核对原20bps基线。

发布入口为 `factor-miner publish-favor-cost-review ROOT --dsn-env ENV_NAME`，写入 `public.favor_research_candidates`，复用全库身份编号。`public.factors` 和 `public.favor_factors` 的原正式状态不变。页面由市场配置的 `cost_review_path` 指向已发布复核目录，在“看结果”中展示研究候选表、公式、完整IC与实际/参考指标。

```sql
SELECT factor_id, trial_id, qualification, ic_mean, rank_ic_mean,
       round_trip_cost_bps, annualized_return, reference_annualized_return
FROM public.favor_research_candidates
WHERE market_id = 'a_share'
ORDER BY factor_id;
```
