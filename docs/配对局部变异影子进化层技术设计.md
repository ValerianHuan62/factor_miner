# 配对局部变异影子进化层技术设计

## 一、研究目标与结论边界

本层只回答一个局部问题：在保持经济假设、股票池、观察时点、交易时点和标签不变时，某一个类型合法的 AST 局部修改是否比父表达式更稳定。

影子结果不是正式因子结论，不进入 PostgreSQL 因子表，不改变主候选是否通过，也不读取确认期选择变体。它只在 2021-01-01 至 2023-12-31 的发现区间产生离散结构偏好，供下一批 LLM 生成表达式时参考。2024-01-01 至 2026-06-30 的确认区间继续只承担确认职责。

本设计借鉴 AlphaG-OPD 的配对兄弟反事实思想，但不复刻 GFlowNet、轨迹平衡损失、KL 教师或梯度回放。

## 二、运行边界

- 默认关闭，通过服务器私有配置 `paired_shadow.enabled` 启用。
- 只在主批次完成发布和 PostgreSQL 投影后运行。
- 当前正在评价的批次不修改、不重启、不补写影子对象。
- 影子失败必须写入独立终态，不能把已经发布的主批次改成失败。
- 不调用外部 LLM，不增加 DeepSeek TOKEN。
- 不写 PostgreSQL；正式 JSON 仍是唯一主存储。
- 不修改主候选 Spec、方向记录、确认结果、`huanNNN` 或多重检验结论。

## 三、候选选择与局部变异

每批从已经冻结且可计算的主候选中，按 AST 哈希稳定排序选择最多三个父候选。选择过程不得读取 IC、收益、显著性或组合结果。

每个父候选生成两个兄弟候选。兄弟候选只能有一个局部差异，并依次尝试：

1. 把一个 rolling 或 temporal 节点的窗口替换为 `5、10、20、40、60、120` 中的相邻可用窗口；
2. 在输入和输出单位兼容时，把 `rolling_mean、rolling_std、rolling_min、rolling_max、rolling_sum` 替换为另一算子；
3. 若前两类不能产生两个合法且不同的表达式，则该父候选写入“无足够合法兄弟”终态。

所有兄弟表达式必须经过现有 typed AST、字段白名单、未来信息和编译校验。变异不得新增经济假设、字段或预处理。

## 四、配对评价

父候选和两个兄弟候选共用：

- 动态沪深全市场；
- 2021-01-01 至 2023-12-31 发现区间；
- 五日 open-to-open 标签；
- 相同状态掩码、交易日历和有效日期；
- 同一评价政策与代码、配置、数据发布身份。

每个表达式先在发现区间按现有协议冻结方向，再把逐日 RankIC 按冻结方向定向。三条序列只在共同有效日期上配对。

共同日期按时间顺序切成四个连续区块。每个区块分别选出定向 RankIC 均值最高者。只有同时满足以下条件才接受局部偏好：

- 同一个兄弟候选至少赢得四个区块中的三个；
- 该兄弟相对父候选的四个区块均值差，其经验下界 `均值 - 1 × 标准误` 大于零；
- 不存在常数序列、非有限值或共同日期不足。

该下界只是小样本经验拒绝规则，不解释为 95% 置信区间。

## 五、影子记忆

每个探针发布一个不可变结果，至少包含：

- 来源自主批次和来源发布批次；
- 父候选和两个兄弟的 Spec/AST 身份；
- 唯一局部修改类型；
- 四区块胜者、一致率、经验下界；
- `accepted、abstained、failed` 终态；
- 数据、政策、代码和配置身份。

下一批 LLM 只接收固定枚举的离散提示，例如：

- `优先尝试更长窗口`；
- `优先尝试更短窗口`；
- `同单位场景优先波动算子`；
- `没有可靠局部偏好`。

不向 LLM 发送精确 IC、收益、证券明细、内部路径或原始影子结果。偏好最多保留最近三个批次，避免旧局部规律长期固化。

## 六、产物与恢复

影子对象保存到：

```text
state/autonomous_research/runs/<autrun>/paired_shadow/
  plan.json
  probes/<probe_id>.json
  summary.json
```

`plan.json` 必须在读取发现区间标签前原子写入。相同内容重复执行直接复用；同一路径不同内容视为损坏。单个探针失败不影响其他探针，最终仍发布完整汇总。

## 七、首轮观察指标

先运行三至四个批次，只观察：

- 合法兄弟生成率；
- 可靠性门控接受率；
- 局部偏好在后续批次的复现率；
- 新批次 AST 重复率与结构多样性；
- 发现方向在确认期的稳定性；
- 影子层新增计算时间。

若三至四批没有形成可复现偏好，保持关闭或删除该层，不扩大到完整 GFlowNet。
