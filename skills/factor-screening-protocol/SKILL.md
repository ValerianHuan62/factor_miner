# 因子固定筛选协议

## 目标与结论边界

把已冻结的候选因子压缩为可解释、低冗余的核心池，并为每个因子记录明确的通过或拒绝原因。

本协议区分三件事：

1. 单因子是否包含稳定的横截面收益信息；
2. 因子加入多因子模型后是否提供增量价值；
3. 最终组合在冻结交易规则下是否具有经济价值。

不得用模型表现代替单因子检验，也不得把通过当前协议的候选直接称为认证 Alpha、生产结论或实盘建议。历史区间已被查看或用于筛选时，只能称为诊断或确认结果；正式新证据需要锁定协议后的未来数据。

## 冻结研究合同

正式运行前登记并冻结以下字段，结果揭晓后不得修改：

| 项目 | 固定口径 |
|---|---|
| 候选族 | 当前不可变账本中的全部候选；失败、重复和中断候选仍留在多重检验族中 |
| 股票池 | 动态沪深全市场，使用显式可计算、可排名、可交易 mask |
| 发现期 | 2021-01-01 至 2023-12-31 |
| 确认期 | 2024-01-01 至 2026-06-30 |
| 信号时点 | 每周最后交易日收盘后形成，只使用该时点已知数据 |
| 周频信号 | `mean5` 与 `last` 分别截面标准化；单因子主信号为两者等权平均 |
| 建仓价格 | 全市场交易日历中信号日后的下一交易日复权开盘价 |
| 退出价格 | 全市场交易日历中信号日后的第六个交易日复权开盘价 |
| 收益标签 | `label_o2o_5d = adjusted_open_exit / adjusted_open_entry - 1` |
| 原始预处理 | 每日截面 1%/99% 缩尾后 Z-score；不得在原始因子层执行这些处理 |
| 组合 | Top50 等权为可执行主组合；Q10-Q1 只作诊断 |
| 成本 | `0.0014 × L1 turnover`，同时报告 2 倍和 3 倍成本压力 |
| 多重检验 | RankIC 使用冻结 HAC 参数；可见统计通过必须满足 Bonferroni 校正 |

若固定建仓日或固定退出日停牌、涨跌停封死或状态表判定不可交易，该样本不进入单因子标签；不得过滤不可交易日后再按每只股票的第 1/第 6 条记录向后移动，否则会把数周或数月收益伪装成五日收益。组合回测若允许延迟退出，必须单独记录实际持有期和未成交状态，不得与固定五日标签混用。

若候选已有事前预期方向，使用该方向。若历史候选缺少可信方向，只允许在发现期根据 RankIC 确定一次数据发现方向，并标记 `direction_source=data_discovered`。确认期禁止翻转方向，Sharpe 也不得用于选方向。

## 第一层：数据与定义门槛

任一条件失败即拒绝，不得用其他指标补偿：

- 有效覆盖率不低于 85%；
- 发现期有效周数不少于 130；
- 公式、方向来源、数据发布、标签版本、交易日历和状态表版本齐全；
- 不存在未来字段、负向 shift、未来填充、标签泄漏或期末成分股回填；
- 截面不长期近零方差；
- 基本面字段按实际可得日对齐；
- 规范 AST 或内容哈希完全重复时只保留一个代表，但不得删除重复记录。

## 第二层：发现期单因子统计门槛

同时保存原始值和方向调整值：

```text
raw_ic_mean
oriented_ic_mean
raw_rank_ic_mean
oriented_rank_ic_mean
ic_std
rank_ic_std
ic_ir
rank_ic_ir
ic_hac_t
rank_ic_hac_t
ic_hac_p
rank_ic_hac_p
```

`IC_mean` 是截面 Pearson 相关，反映线性和幅度信息；`RankIC_mean` 是截面 Spearman 相关，更贴近排序选股。两者都必须报告，RankIC 是主门槛，IC 是一致性门槛。

发现期标准通过必须同时满足：

| 指标 | 门槛 |
|---|---:|
| `oriented_ic_mean` | 不低于 0.010 |
| `oriented_rank_ic_mean` | 不低于 0.015 |
| `ic_ir` | 不低于 0.08 |
| `rank_ic_ir` | 不低于 0.10 |
| RankIC HAC 显著性 | `p <= 0.05 / family_size` |
| 年度 RankIC | 三年中至少两年方向调整后为正 |
| IC 与 RankIC | 原则上同方向 |

分类处理：

- IC 和 RankIC 均通过：标准统计候选；
- RankIC 通过、IC 较弱但同方向：排序型候选；
- IC 通过、RankIC 不通过：线性或异常值敏感候选，不进入核心池；
- IC 与 RankIC 方向冲突：不稳定候选；
- 未通过 Bonferroni：可留在观察池，不得标记为统计稳健核心。

硬门槛之间不得互相补偿；综合分只能给已经通过同一级硬门槛的候选排序。

## 第三层：冻结方向后的确认期

确认期不得重新选择方向、阈值或公式。核心候选必须满足：

| 指标 | 门槛 |
|---|---:|
| `oriented_ic_mean` | 大于 0 |
| `oriented_rank_ic_mean` | 不低于 0.010 |
| RankIC 保留率 | `confirm_rankic / discovery_rankic` 不低于 50% |
| 年度 RankIC | 三年中至少两年方向调整后为正 |
| 成本后主动收益 | 大于 0 |
| 双倍成本主动收益 | 大于 0 |
| Top50 净 Sharpe | 不低于 0.50 |
| 年度主动收益 | 至少两年为正 |

确认期结论只能是：

- `confirmed_consistent`：方向、统计和收益一致；
- `confirmed_weakened`：方向一致但明显衰减；
- `confirmed_reversed`：方向反转；
- `confirmed_unclear`：样本不足或指标冲突。

只有 `confirmed_consistent` 可直接进入核心候选；`confirmed_weakened` 进入辅助池；其余进入观察或拒绝池。

## 第四层：经济表现与风险解释

本层在单因子阶段输出警告和排序信息，不删除已经通过统计与确认期门槛的模型原材料。只有最终组合需要同时满足冻结的收益、成本、换手和集中度硬门槛。

至少检查：

- 十分组收益与有向组号的 Spearman 不低于 0.60；
- 收益不能主要依赖一个极端分组；
- Top50 平均 L1 换手率不高于 1.50；
- 最大回撤不得比同池等权基准恶化超过 5 个百分点；
- 单一年份对累计利润的贡献不得超过 60%；
- 1 倍、2 倍和 3 倍成本均完整报告。

风险解释至少包含行业、`log(市值)`、Beta、波动率、流动性和股价。比较原始信号与残差信号的 RankIC：

- 保留不低于 50%：相对独立；
- 保留 20% 至 50%：混合型信号；
- 保留低于 20%：主要是风格代理。

风格代理不必自动删除，但不得冒充独立 Alpha；只有在组合层提供稳定增量时才能进入辅助核心。

## 第五层：相关性聚类去重

先检查规范 AST 和哈希，再计算可见区间逐日截面相关。满足下式时归入同簇：

```text
max(abs(Pearson), abs(Spearman)) >= 0.75
```

每簇保留一至两个代表，按以下固定顺序选择：

1. 确认期 RankIC；
2. 确认期 IC mean；
3. RankIC HAC t；
4. 成本后 Sharpe；
5. 更低换手。

相关性去重后的候选是模型输入池，不是最终核心池。

## 第六层：简单滚动 Ridge 增量检验

### 是否需要 Ridge

单因子有效性检验不使用 Ridge。IC、RankIC、HAC、分组收益、成本和确认期稳定性已经构成完整的单因子评价。

Ridge 只用于回答多因子问题：在相关因子同时存在时，某个因子或因子簇能否稳定改善预测与组合。它适合这一层，因为它能对共线特征收缩、计算快、行为可审计；它不证明因果机制，也不能挽救未通过单因子数据或泄漏门槛的因子。

### 为什么不强绑 ridge3w

`ridge3w` 是一套历史策略合同，包含特定训练窗、重训节奏、已有特征集、标签和组合实现。它适合回答“新因子是否兼容这套历史策略”，不适合作为“因子是否有效”的通用裁判。

正式筛选使用便携的 `rolling_ridge_v1`：只依赖标准面板、候选因子、开盘到开盘标签和显式配置。历史 `ridge3w` 只能作为可选兼容性对照，不参与硬筛。

### `rolling_ridge_v1` 冻结合同

| 项目 | 固定口径 |
|---|---|
| 特征 | 每个入选因子的 `mean5` 和 `last` 两列，逐期截面标准化 |
| 训练目标 | `label_o2o_5d` 的训练截面 Z-score |
| 结算收益 | 未标准化的 `label_o2o_5d` |
| 训练窗 | 最近 156 周滚动训练 |
| 内层验证 | 训练窗最后 26 周 |
| 标签隔离 | 预测日前最近 1 周不进入训练，等待五日开盘标签完全结算 |
| 重训频率 | 每 4 周 |
| alpha 网格 | `[0.1, 1, 10, 100]` |
| alpha 选择 | 内层验证期逐周截面 Spearman 均值最高 |
| 模型 | 带截距的标准 Ridge，不增加交互项或非线性变换 |
| 选股 | 预测值 Top50 等权 |
| 执行与成本 | 与单因子层完全相同的下一可交易日开盘成交与成本合同 |

必须至少运行三组：

1. 基本面因子单独；
2. 候选因子单独；
3. 基本面因子加候选因子。

模型内的特征选择和 alpha 选择只能使用滚动训练窗与内层验证窗。已用于最终选择的确认期不得再被称为密封 OOS。

对每个相关簇执行 leave-one-cluster-out。模型增量通过要求：

- 删除该簇后净 Sharpe 至少下降 0.10；
- 删除该簇后主动年化至少下降 2 个百分点；
- 加入该簇后最大回撤恶化不超过 5 个百分点；
- 加入该簇后换手增加不超过 15%；
- 配对区块 Bootstrap 中 `P(delta Sharpe > 0)` 不低于 60%。

单因子一般但能稳定改善模型的候选可进入组合辅助核心；单因子漂亮但对模型无增量的候选不进入模型核心。

## 第七层：SPPC 归因

SPPC 仅在冻结模型组合完成后运行，不作为前置筛选器。优先按经济机制或相关簇做组级归因，避免直接对全部候选执行高成本 Shapley 计算。

- 基准组合：基本面因子 `rolling_ridge_v1`；
- 完整组合：基本面因子加候选因子 `rolling_ridge_v1`；
- 玩家：候选因子相关簇或经济机制组；
- 归因指标：净 Sharpe 增量、主动收益和 Alpha；
- 稳定性：全期与滚动 104 周 SPPC。

最终核心要求全期 SPPC 为正、滚动窗口至少 60% 为正、leave-one-cluster-out 方向一致，且贡献不能集中在单一年份。SPPC 是给定模型、组合映射和基准下的条件归因，不得解释为普适因子质量或因果证据。

## 最终分层与审计输出

- 统计候选：数据、发现期统计和冻结方向确认期全部通过，可进入相关性去重与模型增量检验；
- A 级核心：统计、确认、最终组合经济、风险和模型增量全部通过；
- B 级辅助核心：单因子经济表现一般，但模型增量和 SPPC 稳定为正；
- C 级观察：发现期通过，确认期衰减或显著性不足；
- D 级拒绝：方向反转、无增量、严重冗余或数据合同失败。

每个候选必须输出：

```text
factor_id
formula
frozen_direction
direction_source
raw_metrics
oriented_metrics
discovery_result
confirmation_result
risk_exposure_result
cluster_id
ridge_increment_result
sppc_result
final_tier
why_selected
why_rejected
```

缺失指标保持缺失并导致对应门槛失败，不得用零、默认值或其他指标静默替代。
